# 深度相机与雷达采用基座后上方的共用固定支架

用户确认采用 Gemini 335L 与 MID-360S 位于 base_link 后上方（后方为 −Z）、共用单立柱横梁、两个安装座分别调角的布局。相比近旁低位和对侧分置，它兼顾远离机械臂运动区域、官方短线连接同一笔记本、共同标定靶观测以及相对位姿稳定；代价是更易出现共同遮挡，需单独验证。

本决定接受布局方向及预览初始参数，不代表实物加工、无碰撞/无遮挡证明或外参标定已完成。安装后仍须标定两源到 base_link 的关系并验证时间与检测性能；摆放 JSON 不能用作已标定外参。完整坐标、图示、官方依据、仿真结果和落地步骤见[布局与标定方案](../sensor_layout_and_calibration.md)。
