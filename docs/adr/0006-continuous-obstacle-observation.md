# 连续障碍观测与覆盖失效边界

为避免障碍因跟踪或分类状态变化而退出控制输入，用户确认有效几何观测独立于跟踪成功，经校验的固定环境模型与在线观测共同提供障碍信息。必要运动及停车空间失去有效覆盖且无有效保守替代时停车锁存，覆盖恢复并人工确认后继续；这接受额外停机和固定场景模型维护成本，以避免把未知当作空闲。

本 ADR 记录[连续障碍观测决策第一轮](../planning/oscbf-reuse/issues/04-safety-observation.md)的架构结果；速度未知不能当作零，几何输入仍需有效性筛选。距离表示、误差预算、阈值和具体库尚待该票后续讨论。

## 与既有决策的关系

补充 ADR 0003 中“感知是唯一障碍数据源”的范围：固定环境几何也可作为经过校验的约束来源，不能替代在线观测对变化环境的覆盖。保留其静态外参无效拒绝启动、运行期单帧丢弃及持续失效锁存原则；单帧继续运行只在已有有效观测及其适用域内成立。对本 ADR 覆盖失效停车的恢复，用户明确接受覆盖恢复加人工确认；具体恢复接口和其他故障的恢复流程由端到端验证票收敛。

固定模型不得屏蔽在线发现的新障碍，模型与观测冲突仍需显式处理。以上为已决定的目标行为，不代表当前控制链已接入或通过验证。


## 已确认的双源协作方式

用户进一步确认[观测票中的第三轮修订推荐](../planning/oscbf-reuse/issues/04-safety-observation.md)：双源正常互补，按各自采样时刻和视点过滤，再形成保留来源与有效性的统一观测。采用该边界意味着不能用单一最新时间掩盖旧源数据年龄，也不能用一个源的视线否定另一源的有效障碍；上游几何过滤的输出还需要项目有效性适配。具体研究证据和完整处置仍以票据及其链接报告为准。


## 首版过滤接入范围

用户确认首版复用 MoveIt Humble 的基础本体几何过滤，先分别过滤双源可信本体点再融合；阴影射线过滤留待实测需求出现后评估。该选择沿用已有技术栈，同时接受未有证据的遮挡区域仍须按未知处理。完整接口与验证责任以[观测票的最终决议](../planning/oscbf-reuse/issues/04-safety-observation.md)为准；本记录不宣称上游已构建或实机覆盖已验证。
