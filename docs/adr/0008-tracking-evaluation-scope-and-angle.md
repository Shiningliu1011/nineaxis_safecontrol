# 跟踪验收采用逐项结论、真实工具轴夹角和预先声明范围

2026-09-12，用户在 OFF-15 访谈中确认取消加权综合分，采用逐项验收结论；工具轴验收改为 0–π 的真实夹角，既定角度阈值沿用，旧 sin(θ) 保留诊断。此决定明确修订 #14 的小角度报告定义，避免反向 180° 也报零误差；控制内核的 5D 误差和 roll 自由保持。

允许实验在运行前声明路径子区间并单独验收，同时报告绝对弧长位置、区间覆盖、终止状态和整条路径是否验证。区间在采样后不可改写，不能事后剔除差样本。代价是旧总分和大角度下的旧 sin(θ) 结果不能直接参与新验收比较，部分路径实验也不具有整条路径验收含义。

2026-09-12 后续代码审查发现区间外低误差样本会稀释区间内 RMS。用户进一步确认采用严格区间输入契约：越界样本保留供诊断，但阻止声明区间验收通过；评价器不自动按弧长筛选样本。调用方须提供符合预先声明范围的记录，周期采样跨越终点时也须处理边界证据。此取舍避免统计范围随输入尾段改变，代价是不能直接将整段日志传入子区间验收接口。实现及后续验证状态见交接记录。

证据来源与测量边界分开表达，缺失数据和未接受阈值给出证据不足；求解、准入、命令与反馈继续遵守各自的验证边界。用户逐项答复及继承的任务阈值见 [OFF-15 交接](../planning/oscbf-reuse/handoffs/44-offline-tracking-evaluation.md)，使用契约见[跟踪评价说明](../tracking_evaluation.md)。
