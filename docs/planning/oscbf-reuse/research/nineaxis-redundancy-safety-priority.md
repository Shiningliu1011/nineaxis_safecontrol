# 九轴冗余机械臂：任务保持、避障与故障处理的优先关系

研究日期：2026-09-07。服务于[确定端到端验收、性能与故障边界](../issues/06-validation-contract.md)。这是研究建议，未替用户接受新的任务优先级、开关或控制库，未修改运行代码或进行实机验证。

## 结论

后续状态：用户已接受本文的冗余优先、必要时降低进给、正常调节与故障分开的行为路线，完整边界见[阶段决议](../issues/06-validation-contract.md#阶段决议冗余避障与任务调节优先关系已接受)。下文保留研究时的建议表述；具体求解实现和故障恢复规则仍待决策/验证。

九轴冗余应当被主动利用：先争取在保持工具任务的同时调整整臂姿态，再考虑降低进给；正常避障与关键故障应分开处理。此前“任务给安全让步”的原则仍有意义，但不能简化成一遇障碍就暂停、停止或锁存。

建议保留现有 CBFpy/qpax/JAX 统一控制入口、5D 任务和 OBB，研究在同一个安全可行域内协调全臂运动、进给及任务误差。是否需要严格分层 QP，要依据明确的优先级要求与实测收益决定，不能因为“九轴”直接换框架。

## 九轴究竟多出多少调整空间

项目是 1P8R，工具任务为位置 3 维、工具轴方向 2 维，允许工具绕自身轴滚转。在局部有效表示中，设任务 Jacobian 为 `J₅ ∈ R^(5×9)`：

```text
rank(J₅) = 5 时，dim ker(J₅) = 9 − 5 = 4
qdot = J₅# v₅ + N₅ z，且 J₅ N₅ = 0
```

这 4 维是多个关节配合产生的瞬时自运动，不是固定指定四个关节空闲，也不是四个任意方向的避障保证。它包含保持工具轴任务时允许的滚转相关运动，不能再额外加一维。

奇异位置可能使 `rank(J₅)` 降低、数学零空间反而变大，但同时失去某些任务方向的运动能力；接近奇异处，速度限制也可能使所需关节速度不可执行。关节限位、多个 OBB 自碰撞对、环境约束、执行器界限还会限制可用自运动。采用阻尼伪逆时也不能默认投影严格满足 `J₅ N₅=0`，须量化任务泄漏。

把局部安全约束记作 `A qdot ≤ b`，严格保持某个任务速度时实际要判断：

```text
是否存在 z，使 A (J₅# v₅ + N₅ z) ≤ b，并满足所有执行器界限？
```

即使存在 4 维零空间，上式也可能无解。例如障碍直接逼近必须保持不动的工具端，单靠肘部换姿未必能增加工具与障碍的距离。单纯“排斥方向投影到零空间”还可能把有用的避障分量投掉。

## 三类方法怎样择优复用

| 方法 | 对本项目的价值 | 不能默认成立的地方 |
|---|---|---|
| 零空间姿态/梯度策略 | 为换姿、可操作性、远离限位提供名义偏好，可保留效果好的已有实现 | 梯度偏好不是全臂不等式约束；独立投影后叠加可能破坏其他限制 |
| 联合全臂 QP / OSCBF | 将自碰撞、环境约束、关节界限和任务目标统一协调；最贴近现有接入决议 | 任务加权不等于严格任务保持，松弛后的安全约束也不再是硬保证 |
| 严格层级 / 词典序 QP | 若要求“能保持任务就绝不为改善姿态牺牲它”，可明确表达优先级 | 需要处理层级间可行性、数值容差、运行时间；本轮没有选定或验证替代库 |

“先利用冗余、再减进给”是行为优先关系，不要求软件先独立解完任务、再强行叠加避障。可在联合优化中表达，严格程度由约束、分层最优值保留或经过论证的等价实现决定。一个生产入口也不排斥其内部有分阶段优化。

## 推荐交由用户决定的行为策略

| 情况 | 推荐行为 | 是否正常运行 |
|---|---|---|
| 保持工具路径、轴向和原进给仍有满足约束的解 | 用滑轨与旋转关节协调换姿绕障 | 正常避障，不锁存 |
| 原进给不兼容，但降低速度可保持路径几何和轴向 | 自动降低进给，必要时暂缓路径推进；整臂仍可换姿 | 正常调节，不把它记成关键故障 |
| 暂缓进给也不能兼容任务保持与约束 | 暂停工艺任务；只有预先允许且验证过的离轨/退让策略才可执行，否则进入既定停止处置并请求重规划或干预 | 任务冲突，须与传感器/求解器故障区分 |
| 状态/覆盖无效、结果过期、数值失败，或无法取得可执行的有效约束解 | 不执行未经验证的运动；调用已经定义并验证的故障处置路径 | 关键故障恢复按待决契约，不因有冗余而忽略 |

这里的“减进给”是路径参数随时间推进得更慢，不是把九个关节速度随意统一乘一个系数：动态障碍正在接近时，简单缩小控制量可能破坏已满足的相对运动约束。路径误差校正、任务容差、允许退让方向与加减速连续性都要一起定义。

从优化角度，可研究 `J₅ qdot = v₅(s, sdot, error)`，把路径推进速率作为有界调节量；这是设计示意，不是可直接投产的 QP。是否严格保持工具位置/轴向、允许多少误差、是否允许自动离轨，需要活人决策，不能拿任意权重替用户回答。

## 两个容易误判的状态

**QP 不可行不等于物理世界不存在绕行路径。** 它可能只是当前局部模型、当前任务等式和当前保守约束没有共同解；也要区别求解器超时、数值故障与经可靠诊断的不可行。不能因此宣称机器人绝无出路，也不能跳过约束强行绕行。重新规划负责寻找跨时域的路，当前控制仍要有有效处置。

**零速不等于动态安全。** 对移动障碍的局部屏障可写作 `hdot = (∂h/∂q) qdot + ∂h/∂t`。当 `qdot=0`，障碍靠近仍可能使 `hdot<0`。停止是故障处置动作，不是对任意外来物体的安全证明；同样，停止路径本身包含减速时间与空间，不能等同于瞬时制动。失去可信观测时也不能凭这一事实启用未经验证的盲目退让。
