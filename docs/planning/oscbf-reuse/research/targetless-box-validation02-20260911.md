# 第二位置纸箱验证（2026-09-11）

用户更换纸箱/椅子位置后采集，按此前指示假定传感器未移动；此假定尚未通过独立位姿测量验证。使用第一组数据已经保存的三个候选矩阵，未重新拟合或调整矩阵。

原始bag：`.scratch/targetless-calibration-trial/bags/box-validation-02/`，提取154帧雷达；证据及提取/验证脚本在 `.scratch/targetless-calibration-trial/results/box-validation02/`。彩色图可见箱体主要正面，顶面较窄。首8秒雷达点云与首帧注册相机点云用于本表。两云过滤有限值、0.3–12m，1cm体素。

验证前依据相机图像指定箱体正面内部四边形ROI：[(307,214),(387,213),(389,290),(309,292)]；使用本次CameraInfo和畸变将注册点云投影选取884点。该ROI按图像位置定义，不按三种外参残差筛点。将同一组相机点分别变换到雷达系，计算到完整雷达云的单向最近邻距离；未进行目标端同实体语义筛选，不能排除最近邻落到其他表面。

结论：NID候选在新位置的正面局部表现最好；这是新数据对既有候选的验证，支持继续研究该候选，不能证明外参误差小于20mm。全场景指标仍包含非重叠区域，不能据其排序直接选择外参。该新数据此后已经用于评价/选择候选，不应再当作完全未使用的最终验收集。

单面内部最近邻主要验证法向一致性，无法可靠检查沿面平移、箱棱和全部旋转自由度；本次未测量纸箱真值尺寸/位置，亦未进行相机到基座验证。下一组应保持传感器固定，将纸箱旋转使两侧面都明显可见，并改变距离，补充箱棱与多个朝向的验证；最终仍需新的未使用验收数据。

无运行外参或calibrated状态变更。
