# OFF-02：无法证明时应细分、缩域还是换姿态？

日期：2026-09-15。研究范围：决策②的处理顺序。后续状态：用户已接受研究建议。此前已接受的完整蝴蝶任务、固定起点筛选、相邻免检、OBB 表示和按需补对规则继续适用。

## 结论

**应把原先固定的“细分→缩域→换姿态”修订为“先分类失败，再选动作”。** 任务完整性仍建议优先保留，但真实 OBB 重叠应直接换候选，不能先对含重叠点的区域反复细分。证明预算耗尽只能报告未决，不能说没有解。

| 失败类型 | 可核查的证据 | 下一步建议 | 不能得出的结论 |
|---|---|---|---|
| 输入无效或条件缺失 | 非有限 q、模型身份不符、缺少误差/停止界 | 修复输入；几何证据与运行准入条件分别报告 | 缺少物理条件不能填零后报准入通过 |
| 具体构型 OBB 相交/接触 | 稳健独立判据与明确 q；数值边界先记未知 | 若在任务必经候选路径上，改关节姿态分支；若仅在过渡上，改过渡或起点；若只在可选外围，排除该部分 | 细分含该点的子区域不会消除相交；补在线约束也不会使该点变为可准入 |
| 点处分离，区域下界不够 | 点距离下界有效，但减去区域运动变化界后不足 | 先利用相对运动减小保守性，再有预算地自适应细分 | 下界不足不等于已发现碰撞；增加普通采样数不等于连续证明 |
| 额外活动范围过大 | 必需路径/包络可覆盖，可选范围导致失败 | 可收窄可选冗余活动范围并重新验证覆盖、连通与可执行条件 | 不能裁掉必要误差/反应/停车范围；不能只留下互不连通的安全小岛 |
| 必需停车/反应范围过大 | 有依据的状态、速度、反应和制动模型 | 可评估降速后重新计算包络，或换姿态/过渡 | 降速不能消除静态 OBB 重叠；本票缺实机模型时不能量化保证 |
| 计算预算耗尽、数值不确定、候选搜索失败 | 未验证单元、最小单元尺度、运行量及失败记录 | 输出“无法证明/未找到”，保留已通过部分及后续建议 | 不能标整条任务通过，也不能证明所有 IK 分支无解 |

以上动作是按失败原因分支，不要求每个候选依次走遍所有动作。改变任务路径/工具轴要求或碰撞表示仍需另行对齐，不由本次研究自动决定。

## 依据一：连续检查依赖有效的变化上界，不是盲目加密

[OMPL 官方状态验证文档](https://ompl.kavrakilab.org/stateValidation.html)区分状态检查与运动检查；默认离散运动检查可能漏掉采样间无效状态，过密又会增加成本。[MoveIt Humble OMPL 文档](https://moveit.picknik.ai/humble/doc/examples/ompl_interface/ompl_interface_tutorial.html)给出相同限制。这里说明工具机制，不把它当作本仓库自定义 AEB 插件的完整审计。

[Bury 等，2019，§II-B、III-A](https://arxiv.org/html/1909.10857)以物体间距离下界和相对运动速度上界构造可证明无碰撞的路径区间，再覆盖整段路径。其输入是规定的路径；不能直接外推为路径周围任意九轴组合都有效。论文也将父子连杆对排除，但本项目相邻免检的授权来自用户。

### 面向本项目的推导（尚非实现或证书）

在一个关节区域 C 的参考构型 qc 上，若某对盒体的分离距离下界为 L，且该区域内两盒体相对变化导致的距离减少不超过 B，则有：

`区域净空下界 ≥ L − B − ε_num`

其中 ε_num 必须覆盖计算误差；它不能只取一个未经验证的浮点常数。若该下界严格超过声明的所需几何净空，则可提供该区域的充分证据。未超过只说明这条充分判据不够，除非另有具体碰撞反例。

可由区域内有效的点运动界构造 B，例如 `Σ Lk·rk`：rk 是该轴区域半宽，J1 用 m，其余用 rad；Lk 来自区域内所有相关盒体点对该关节的运动上界。旋转关节可以用有依据的最大力臂估界；平移关节使用平移量。不能用中心构型一次雅可比或采样梯度最大值替代整个区域的上界。运动包络已包含的误差/停止项不能再次扣除。

细分的收益是减小局部 rk，并在各子区域重新取参考点和验证下界，同时保持原区域被子区域完整覆盖。它改变证明粒度；缩域则真的减少允许动作集合。这两者应在报告中分开。

若实际净空始终严格高于要求、有正确且收敛的界和足够计算资源，细分才有希望覆盖整条路径；接触、缺参数或预算受限时没有无条件完成保证。

## 依据二：自碰撞优先采用相对运动，避免无效缩域

源码 `portable_oscbf/work/kinematics_data.py` 是串联链。在 Linki 坐标系看下游 Linkj，二者共同上游关节施加的刚体变换相消。因此自碰撞几何只依赖两者之间的活动关节；对上游共同轴的范围不应按两盒在世界系分别移动后直接累加。

例：Link3/Link5 的相对位姿由 J4、J5 决定；单独更改 J1、J2、J3 不改变两者净空。故遇到这对瓶颈时，只缩 J1 行程没有用。base_link/下游连杆对以及环境碰撞不能照搬“J1 相消”，因为 base_link 和环境不随 J1 同移。

这是根据当前链结构的工程推导；后续实现须逐对生成活动关节依赖，验证索引和模型身份，而不是硬编码所有对都忽略某轴。九轴任务域仍需检验全部相关条件，不因某一对低维化就缩减任务自由度。

## 本轮独立点检查：验证“先判断失败原因”的必要性

运行：[probe.py](probe.py)，输出：[probe.json](probe.json)。脚本仅加载源码运动学和 OBB，以 NumPy SAT 和 FCL Box–Box 比较：零位、`task_target.py` 中六个自然 IK 种子，各检查 36 个非相邻对，共 252 个配对样本。

```bash
PYTHONDONTWRITEBYTECODE=1 python3 docs/planning/oscbf-reuse/research/off02-failure-routing/probe.py > docs/planning/oscbf-reuse/research/off02-failure-routing/probe.json
```

- 实际退出 0；NumPy 1.26.4，python-fcl 0.7.0.11。输入文件 SHA-256 随 JSON 保存。
- 252 个样本中 SAT/FCL 盒体碰撞状态分歧为 0；探索性 `1e-9 m` 边界带内样本为 0。该边界带不是正式准入阈值或计算误差证明。
- 前四个自然种子均有 **Link3/Link5 OBB 重叠**；SAT 最大轴间隙约为 **−8.277 mm**（投影分离量，不声称是网格穿透深度），FCL Box–Box 确认相交。该对目前未在 14 对在线表中。
- 零位和后两个自然种子未发现非相邻 OBB 重叠。这只是点证据，不证明任务、局部区域或停车包络可行。
- 对 natural_seed_1 与 natural_seed_3，仅 J1 从 0.30 m 改为 0.47 m，排除 base_link 对后，SAT 最大轴间隙变化最大 `5.55e-17 m`，与共同平移相消的推导一致。

**这些 q 是 IK 初始种子，不是 IK 最终解，也不是跟踪路径。** 因此前四个种子重叠不能证明任务失败，后两个种子分离也不能证明它们能完成任务。这组检查只能支持先筛候选、按实际失败类型分支，避免对明显相交候选盲目细分。

本轮未运行完整 IK、过渡或跟踪仿真，未计算新连续区域证书，也未重跑真实网格扫描。既有 [第二轮几何报告](../geometry-audit/kernel-validation-2026-09-12/REPORT.md)记录了 OBB 相交而网格分离的情况，应保留模型度量区别。

## 按需补对的位置

省略对若在拟允许区域内不能证明始终有足够净空，可按既定决定评估加入在线约束，以限制运行中的运动；随后须验证新的受约束路径、准入重叠检查和区域契约。相邻对继续免检。

“加入约束”不能替代重叠判据，也不能将静态相交的起点/必经点变成有效点。若单个 OBB 太保守以至于任务受阻，网格可用于解释原因；换成网格放行或重做 OBB 包络属于另一个会影响表示和证据的决定，不在此自动执行。

## 建议的停止条件与交付

具体离线计算预算由实施时记录（单元数、深度、时间等），不把它们当安全阈值。达到预算且剩余单元未验证时终止本次尝试并报告未知；只有严格覆盖声明的区域才能报区域通过。

每个失败记录模型身份、碰撞对、q/区域、路径段、判据及原因；把“模型内有反例”“界不足”“参数缺失”“搜索未找到”分别记录。局部几何证据、完整任务覆盖和运行准入条件分开交付。

**后续用户决定：接受按失败原因处理、优先保留完整任务、无法完成则如实交付局部证据和未覆盖原因的路线。** 方法研究和点检查已经完成。实际连续界、区域连通、任务可执行性和物理停止条件仍待后续实现/证据。
