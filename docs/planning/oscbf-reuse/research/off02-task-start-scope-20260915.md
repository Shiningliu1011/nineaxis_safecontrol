## 建议：先一个固定起点实例，再扩展为区域

1. **任务固定为现有完整蝴蝶路径与 5D 工具轴要求。** 冻结实际文件、变换、圆柱参数、控制配置、机器人模型及附件声明。工作区已有未提交轨迹修改，保留这些修改并记录其内容哈希，不能仅使用 Git HEAD 标识输入。
2. **具体 q 由离线筛选产生，不让用户手填九个数，也不直接指定零位。** 优先选择一个可复现、通过独立非相邻 OBB 检查的候选；先检查任务首点 IK 的多个分支，再选择能与允许起点通过有效过渡连接的分支。保存实际 q、IK 结果、过渡及完整跟踪状态；随机种子只作辅助复现信息。
3. **把几何研究分为三段，但整项任务目标保持“过渡＋完整跟踪”。** 先检验任务首点局部邻域，再沿完整跟踪扩展，最后连通固定起点的过渡段。每个阶段允许给出失败证据；局部成功不能升级为整条任务已覆盖。固定起点本身也需具有明确的允许误差范围，而不只是一点。
4. **区域围绕实际九轴路径形成，并检验连续界。** 首轮不是全关节限位笛卡尔积；也不是只检查记录里的采样点。正常运动区域与停车/误差扩展分开表达。未知停车和模型误差项保留接口与未知状态，不填写虚构物理阈值。
5. **不因为 OBB 无法通过而静默换成网格放行。** 网格/FCL 作独立对照；若某些省略非相邻对在目标构型 OBB 相交，即使网格分离，也需报告当前 OBB 路线对此分支的限制，按既有按需补对/收缩路线评估。无法证明要保留负结果。

### 方案比较（工程判断）

| 候选范围 | 收益 | 成本/缺口 | 建议 |
|---|---|---|---|
| 一个固定起点及相连的蝴蝶任务区域 | 可复现且直接服务现有任务 | 尚需筛选具体 q 并验证连续覆盖 | 首轮采用 |
| 少量固定起点共同覆盖 | 能比较不同接近姿态 | 每条过渡和连接处均增加验证工作；当前无必须覆盖的起点清单 | 后续扩展 |
| 全限位随机起点 | 探索范围广 | 随机成功不能证明所有组合；已知非相邻重叠反例存在 | 用于反例搜索，不作为首轮通过声明 |
