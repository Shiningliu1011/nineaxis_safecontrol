# [07B] 选定冗余目标与优先级

- Tracker：[选定冗余目标与优先级](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/16)
- 日期：2026-09-10；HITL 行为决策已收敛，实施与数值验证交后续票。
- 前置：[冗余策略对比交接](5-redundancy-strategies.md)及其研究证据；既定 5D 路径语义沿用原决议。

## 用户已确认的决定

用户原话：“我想的冗余调整是在有外部障碍物的时候，能够做到在躲避外部障碍物的同时还能保持末端的高精度工作”。

随后对以下建议回复：“同意你的建议”：

1. 原进给下能够兼顾避障和末端精度，就通过九轴协调保持工作。
2. 原进给下无法兼顾，就降低进给，保持原路径和工具轴精度。
3. 降速仍无法兼顾，就暂停任务并进入已验证的安全处理路径。
4. 不允许为了继续绕障而让末端暂时超出既定精度范围、之后再返回路径。

用户随后对“满足精度要求并留有经验证的误差余量时，优先保持进给；接近精度边界时再降速”回复：“接受建议”。因此精度允许范围内不单纯为追求更小误差而进一步降速。

核心目标是外部障碍下的冗余避障与末端精密作业。上一轮助手提出的“限位余量优先于近奇异改善”没有获得用户确认，不作为决议。关节限位与任务能力作为约束和支撑条件处理；roll 自由等既定语义不重问。

任务暂停不等于在任意动态障碍工况中零速度天然安全；具体安全处理沿用故障/执行保护决议，并由后续几何、可行性与执行证据验证。

## 当前事实与证据边界

前置实验是两个初态、三候选、固定末端、无外部障碍的局部对照，未触发活跃安全约束。它不能证明用户要求的外部障碍下精密路径作业能力。当前加权目标与显式梯度均不自动保证严格任务优先；不据此启用生产零空间策略。

## 优先关系与恢复规则

行为契约为：在安全与执行约束、带经验证余量的末端位置/工具轴精度约束内，优先保持允许的任务进给；原进给无法兼顾时调整路径进给并重新求解九轴协调动作。不能只把最终关节速度同比缩小，也不能用有限权重宣称这些约束永不被低层目标突破。具体采用约束优化或等价层级实现，交控制接入票验证，不强制更换求解库。

不启用未经证明有收益的关节回中或现有六维可操作度梯度。它们仅为比较候选，不能凌驾于外障下的末端精度与任务进给要求。限位和任务能力是支撑条件，不把未经用户确认的次目标排名变成生产策略。

恢复规则直接继承[已接受的任务恢复决议](../issues/06-validation-contract.md#阶段决议任务恢复与预算定案方法已接受)：正常冗余换姿、降进给或暂缓进给，只有在数据和控制持续有效、未进入任务冲突/故障、仍满足任务误差及经验证稳定性/滞回条件时，才自动平滑恢复。任务冲突后的执行须人工确认；故障锁存按既有检查与人工恢复规则处理。本票不新增自动离轨许可。

## 后续验收与实施门

继续复用现有九轴/5D 任务、OBB、JAX/CBFpy/qpax 基础，固定版本和许可证见前置研究。本票没有选择新的求解器或具体层级算法；具体适配交控制接入票按行为契约比较。没有证据支持直接启用现有显式梯度或替换整套控制库。
