# LiDAR 外参标定现场准备与记录清单

对应任务：[激光雷达外参标定与独立验收并写入真源](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/95)。

2026-09-27，用户已连接 LiDAR 和机械臂，尚未准备标定参考。设备身份、点云接收结果和样本见[现场连接记录](session-20260927.md)。
本清单用于准备现场输入，完成验收仍需真实测量、求解及运行记录。

## 到场携带与核对

- [ ] 采集计算机、已使用的传感器供电与网络连接线缆。
- [ ] 现场已有标定靶、尺寸资料及固定夹具；记录靶标类型和实际尺寸后确定适配工具。
- [ ] 适合现场尺寸测量的工具，以及尺寸已知的独立验收物体。
- [ ] 可供记录原始点云和参考数据的存储空间。

## 安装与设备记录

- [ ] LiDAR 实际型号、序列号、固件版本、操作者和采集日期。
- [ ] 支架与安装座已紧固，线缆固定，采集期间安装关系保持不变。
- [ ] 支架、安装座与传感器外壳的实际尺寸、位置和参考坐标，供后续几何资产使用。
- [ ] 驱动名称、版本、配置文件、实际点云 topic、消息类型和 `frame_id`。
- [ ] 点云字段与单位、时间来源、静态点云质量及靶标可见情况。

## 正式采集前确认

- [ ] 明确靶标观测如何得到 LiDAR 到 `base_link` 的变换；保存靶标参考点和参考坐标定义。
- [ ] 使用末端靶板时，确认固定方式及同一静态样本的真实九轴关节反馈能够保存，包含 J1、关节名称、单位、时间和模型版本。
- [ ] 确认独立验收的参考位姿和已知物体位置如何测量。
- [ ] 确认现有求解工具能够读取现场数据，再按其输入要求记录完整样本。

现场人员负责实体安装和所需姿态调整；本任务的采集、计算与记录操作不发送真实机器人运动命令。

## 分别保存的数据

1. 求解集：原始点云、对应靶标观测、真实参考位姿、样本编号和采集时间。
2. 独立验收集：未参与求解的靶标位置与姿态、已知尺寸物体的点云及参考测量。
3. 重复测量：保持安装条件一致时的重复数据，用于检查结果重复性。
4. 数据说明：工具与模型版本、配置、靶标尺寸、坐标方向、单位以及原始文件 SHA-256。

数据目录到场后确认并写入任务记录。样本数量和姿态要求随已确认的求解工具确定；正式采集前明确区分求解集和验收集。

## 验收需要取得的结果

- 独立外参位置误差不超过 20 mm，角度误差不超过 5°。
- 已知尺寸物体的点云位置误差不超过 20 mm。
- 保存误差计算方法、每个验收样本的结果和重复性记录。
- 通过验收后，将真实结果及 provenance 写入 `config/sensor_extrinsics.yaml`。
- 重新构建与部署，取得节点实际加载路径、文件 SHA-256、`calibration_id` 的一致性证据，以及启动日志和 `/perception/calibration_status` 输出。
