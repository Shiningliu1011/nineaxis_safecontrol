## 结论范围与恢复条件

本次证明这组参数下的九轴连续参考存在 J4 跟踪和范围问题。此前主要位移为 J1、J7–J9 的六组结果继续限定于各自工况。当前不能确认内部滤波、伺服动态、机械因素或其他设备规则对 J4 的具体作用，也没有独立角度测量用于确定机械位置误差。不得扩大已检查范围来接受这次反馈。

针对是否观察到 J4 抖动、碰触支撑物或异常声音，用户回复“没有看到或听到这些现象”。该现场观察没有提供独立角度和动态响应测量，物理原因继续保持待定。厂家 SDK `preset_angle` 第 245–293 行和 ROS C++ `tp_subscriber.cpp` 的 mode 0 编码与本次发送方式一致；本批次内部响应和模式 0 的完成状态仍需设备依据。

连续模式 0 的恢复需要取得本批次实际响应及参考采用依据，说明 J4 异常和完成标志含义，并具备有效的独立停止与支撑条件。现场供电、机械参考、配置、故障及新的静止反馈按具体动作核对。通用 ROS live 准入要求保持生效。

## 重新供电后的设备依据

用户确认“急停断电后重新上电，当前有支撑”。只读查询取得九轴约 24 V、闭环状态 8、各项故障为零，运行参数恢复到保存值。J2–J6 的位置增益、速度增益和速度积分为 `10、0.2475、1.604`；本地厂家《DrEmpower 系列产品电机备选 PID 参数表》物理第 2 页的 B25-PD-36-G 对应值为 `22、1.116、4.095`。用户不清楚参数调整历史。实际配置与表格存在差异，具体适用版本及对异常的作用仍需核验，未改写 PID。

原始帧复算显示 J4 在约 39.036 ms 主机接收间隔内变化 −0.045793°，这两条反馈对应的最近主机广播目标没有变化；扭矩读取分别为 6.18、5.34 Nm。该结果保存设备响应及主机时间，不能由此单独确定机械原因或设备采样速度。

研究程序的阶段切换要求完整五秒静止窗口发生在新阶段开始之后。模式 0 的原始故障记录及源码保持其执行版本；上述程序调整没有提供模式 0 再次运动通过的结论。后续原生位置模式完成单组九轴目标，到位后连续保持约 52 秒，见[实机记录](native-positioning-experiment.md)。

## 归档与程序验证

原始归档为 [`nineaxis_continuous_failure_20261030.zip`](../../../tests/data/nineaxis_continuous_failure_20261030.zip)，SHA-256 为 `a66b4a0240ac70521a25c19231b3a6ea267322d64ec42b81d290631fd6e932ae`。31 个数据及源码成员均由 `provenance.json` 保存字节数和摘要，另有来源清单本身；包含两次采集、原始帧、三次预检查、实际源码、坐标配置和用户停止声明。

公开离线入口及命令见[诊断说明](../../motor_positioning_diagnostics.md#九轴连续参考中止记录的回放)。`JointTableControl.encoder_targets` 统一完成九轴 SI 坐标到设备角度的转换，524 批实际请求与该转换逐项相符。运行配置新增 `--scope operating`，回放同时核验配置字段与原始回复。当前修改后的研究程序尚未重新执行实机实验。

连续参考连接现在必须在打开串口前提供 `TrackingProbeBounds`，使用同一已检查范围经方向、零位转换得到的九轴设备角度上下限。全部快速反馈与预设自动回复都在接收时检查；遇到范围违例，原始帧保持记录，连接保持失败状态，随后预设和广播被禁止。发送目标也检查 float32 编码后的角度。原始第 31015 帧由该检查拒绝，发生在随后广播之前。该修改用于停止后续发送，独立物理停止仍需对应证据。

定位、表格执行、只读证据、连续参考回放、原始日志和有人值守保护的 138 项相关回归通过。范围检查补充后，回放、连接、调试参数、J1 及协议的 160 项相关测试通过；补充部分预设中止回放后，证据、回放和有人值守的 79 项测试通过。六个生产源码文件和研究执行程序通过类型检查。该结果属于程序验证，九轴完整往返、物理精度及独立停止尚未通过。设备规则待确认项见[设备确认事项](manufacturer-questions.md)，载荷、测量和停止条件见[现场条件](field-conditions.md)。
