# 九轴原生单组定位实机验证

现有 `scripts/joint_positioning.py` 接受 `--joints` 输入一组九轴绝对目标，J1 使用 mm，J2–J9 使用 °。本次目标为 `[2, 1, -1, 1, -1, 1, 1, -1, 1]`，全部九轴实际移动、到位并持续保持。运行方式见[九轴定位](../../joint_positioning.md)。

后续 ±7° 与 J1 50 mm 的结果见[较大目标实机验证](larger-positioning-experiment.md)。最新状态见[J1 多圈计数实验与零位恢复](j1-multi-circle-experiment.md)。

## 方法与适用范围

操作者确认支撑允许这组运动、运动范围内无人并在断电开关旁持续看护。指令速度为 J1 0.25 mm/s、J2–J9 2.46°/s，加速度分别为 0.05 mm/s²、0.3°/s²。设备 PID 保持读取值。

本次完整关节范围覆盖实际起点、目标及执行容差，并检查全部 36 个非相邻凸 mesh 组合。区间检查保留覆盖的子区间及距离界；扣除 10 mm 自身间距后，最小证明裕量约 0.546 mm。外部空间由现场操作者核对。该模型检查限定于本次姿态范围。

定位入口按规格 R07–R09 使用 J1 1 mm、旋转轴 0.1° 的目标误差阈值。J1 的 1 mm 按传动转换为输出轴 72°；反馈连续性、速度、静止窗口、设备故障和关节范围分别检查。单轴计数研究保留各自记录中的参数。

本次取得原生单组定位与保持的设备反馈证据。共同平滑进度、J1 500 mm 行程、独立机械精度、最大载荷及正式连续轨迹仍按 #184 对应任务验收。连续模式 0 的 J4 异常原因尚未确定。
