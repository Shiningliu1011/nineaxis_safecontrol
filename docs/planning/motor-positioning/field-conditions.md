# 九轴定位与蝴蝶曲线现场条件

对应 #187。用户确认 J1 水平沿基坐标系 Z 轴前后移动，基坐标系 +Y 向上，输出轴直连丝杠。本次动作实验由用户授权，并确认在现场看护、配有急停按钮、失能转动有支撑。完整装配质量和最大计划载荷待定；独立测量和停止响应尚未完成验收。[现场条件数据](../../../tests/data/j1_experiment_field_conditions_20261030.json)保存方向、已知条件及未知数值。

本次现场提供卷尺，用户确认最小刻度 1 mm；J1 的人工往返读数为 500→495→500 mm。测量不确定度、参照点完整几何及连续时间记录尚未取得，现有记录用于核对 5 mm 相对位移。历史[激光跟踪仪准备记录](../laser-tracker-calibration/decisions.md)记载仪器、靶球和安装座尚未具备；本次尚无旋转关节独立角度或末端三维精度测量设备的确认。

本次继续研究时，用户确认“载荷不知道，测量有卷尺”。完整移动质量、工具质量和最大计划载荷继续记为未知。型号沿用既有记录：J2–J6 为 B25-PD-36-G，J1、J7–J9 为 B06-PA-36-G。原始声明与本次只读设备数据共同保存在 `tests/data/motor_positioning_research_20261030.zip`。

后续非零位置断电核验由用户支撑固定姿态并人工切换电源，报告卷尺读数为 499→499 mm，并明确“499是到末端的距离”。该数值记录为卷尺测点到末端的距离，J1 坐标另由设备反馈保存。实际断电时间、各轴独立角度和距离测量不确定度未知；原始声明及前后全部读取见[同步接口与断电记录](live-interface-experiments.md#非零位置断电核验)。

此后用户确认固定已解除、支撑不妨碍运动并能持续看护。[九轴连续参考实验](nineaxis-continuous-experiment.md)因 J4 范围违例中止，程序未确认停止；用户回复“已经急停，机械臂停止并有支撑”，随后说明“急停断电后重新上电，当前有支撑”。重新读取确认九轴约 24 V、闭环状态 8、各项故障为零；停止触发时间、停止时间及距离仍未测量。

[原生单组定位](native-positioning-experiment.md)执行前，用户确认“支撑允许运动，范围内无人，我在断电开关旁看护”。本次九轴目标执行及连续保持完成，原始现场声明与设备记录共同归档。PID 调整历史由用户确认为未知。

| 最终目标越过量 | 从接近目标到保持的完整双向记录，按照运动方向计算最大越过量；端点仍遵守关节范围 |
| 实际同步 | 共同计划、发送、采用和实际反馈分别记录，说明各时钟、采样分辨率及不确定度，计算实际启动与到位时间差 |
| 蝴蝶曲线 <2 mm | 采集前声明整段路径，独立末端测量覆盖低速及较高速度的完整运行；按路径顺序及端点三维距离评价，另存同一时刻参考误差 |
| J1 换向 | 完整位置、速度、加速度记录及其估计方法、时间依据、测量不确定度，覆盖所有往返和轨迹衔接 |

测量能力需要足以支持 #184 的数值通过条件。设备反馈用于执行监测；独立测量用于物理精度评价。原始仪器数据、设备反馈和程序报告分别保存，保留单位与时间转换依据。

## 可执行的测量方法和记录要求

| 对象 | 测量方法 | 原始记录与判定 |
|---|---|---|
| 装配质量 | 在独立支撑和断开运动能力的条件下，用有校准或校核依据的称量设备分别测量全部移动装配、实验工具及计划载荷；防止部件重计或漏计 | kg、设备型号、分辨率、不确定度、各次原始读数、安装位置和质心说明；总质量和最大计划载荷必须明确数值 |
| J1 相对位移 | 在固定基座和 J1 移动部分建立直接沿运动轴的两个测量基准，记录同一工具和其他轴姿态；用卷尺核对已声明的相对位移 | 保存起终点读数、参照点、方向及刻度；末端到任意物体的距离变化仅在参照几何可核实时转换为 J1 位移 |
| J1 定位与保持 | 使用独立位移测量设备，连续记录接近目标、稳定和至少 5 s 保持；双向接近同一目标 | 目标及实际位置 mm、原始时间、测量有效性、采样间隔、不确定度、范围边界；当前卷尺记录没有连续精度验收依据 |
| J2–J9 角度 | 在单个被测关节的前后连杆分别建立角度基准，使用独立角度仪，或用具备可观测性和不确定度分析的多点空间测量求取相对转角 | °、轴线和测量基准、其他关节状态、校准文件、双向记录；单个末端点 XYZ 的九轴反解不能独立证明每轴精度 |
| 整段末端路径 | 使用可导出带时间和有效性标记的三维测量设备，建立其坐标系到 `base_link` 的独立标定及测量点到 TCP 的固定关系 | 测量点 XYZ、时间、坐标变换及不确定度；覆盖两类速度下的全部声明区间，按项目既有路径顺序和端点规则复算 |

| 停止响应 | 在独立支撑和有效位置范围内，用与控制程序独立的测量记录停止触发、实际运动到完全停止以及停止后支撑；按对应现场任务和已批准动作执行 | 触发到完全停止的时间、各轴运动距离、最不利装配和速度、全部失败记录；所得上限用于 watchdog、运动范围与停止范围检查 |

仪器选择与最终结论同时考虑分辨率、校准误差、安装误差、坐标变换、时间关联和采样间隔。报告保留测得误差及其不确定度；不足以区分是否满足数值上限时，记录为待定。连续采样中的缺失、失效或未覆盖区间保持可见，不用插值后的数值替代未取得的独立测量。

## 测点和完整运行的覆盖

J1 全行程的设备能力和执行保护满足后，覆盖 0 mm、500 mm、内部位置及两个方向的整段运动。内部位置可采用 50、125、250、375、450 mm，并增加正式轨迹实际使用的局部目标；这组测点用于组织验收，有限测点不能单独证明任意目标均有效。每个目标分别取得两个接近方向的全过程记录和稳定后的至少 5 s 独立测量。端点动作遵守 0–500 mm 边界，目标越过量与范围违例分别判定。

转动关节覆盖既定操作范围内的零位、正反向内部目标和正式轨迹需要的位置；实际范围与完整路线检查确定可执行测点。每轴的两个接近方向、到位、保持和目标越过量采用同一测量定义。J5 两端的上电表示需要设备依据和实际机械参考，测量计划保持两端身份。

低速及较高速度的蝴蝶曲线分别在运行前声明整段路径、工具、载荷、速度和时长计算来源，连续执行包含全部 J1 换向的完整任务。原始三维测量先完成独立时间与坐标转换，再按既有路径评价计算整段最大误差；全部声明区间均需满足严格 <2 mm。设备误差、时间误差和测量不确定度随结果一同报告。

## 标定、限制和恢复的证据交接

TCP、工件与测量坐标系的标定应保存原始数据、变换、单位、独立保留点残差及有效装配身份。速度和加速度逐轴注明来源、载荷和供电条件；设备回读的最大参数只代表配置。完整限制需要同时考虑驱动采用、实际跟踪、停止响应、碰撞范围和测量能力。

本次十秒只读测试的单次请求及九轴周期统计见[设备依据](device-evidence.md#当前连接的复核与反馈时序)。主机接收间隔没有提供设备采样时间、实际同步、伺服跟踪或通信中断后的物理停止证明。`can_timeout_ms=0` 和独立停止尚未测量的事实继续交给 #191 处理。

通信中断、编码器故障、位置失效或停止触发后，结束当前任务并保存原始原因。后续恢复需要处理对应原因、核验独立机械参考及设备配置，重新取得有效静止反馈和覆盖运动及停止范围的检查结果。现场操作者看护、急停按钮和支撑的既有记录，与实际停止时间和距离测量分别保存。

## 执行前仍需完成的现场工作

1. 确认并称量完整移动装配、工具及最大计划载荷，记录安装及供电条件。
2. 提供独立测量设备资料、校准依据及原始导出样本，确定测量基准和时间关联方法。
3. 补足 TCP／工件标定、逐轴能力、伺服与反馈时序、完整停止响应及独立保护证据。
4. 在每次动作的具体授权下，使用有效坐标和覆盖运动及停止区间的路线证明执行现场测量，保留异常和未完成结果。
