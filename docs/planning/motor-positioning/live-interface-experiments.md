# 同步接口与断电恢复的实机记录

#186 已完成共同时间定位、连续参考各三组小范围实机实验，以及一次由用户固定姿态并操作电源的非零位置断电核验。主要位移轴为 J1、J7、J8、J9，九轴均接收完整目标并持续读取反馈。原生共同时间定位在本次条件下未实现共同运动进度；20 Hz 连续参考的实际进度差明显减小。完整行程、全部旋转轴的主要行程、独立物理精度及长期断电保持继续按[任务清单](tasks.md)验收。

后续[全部九轴连续往返实验](nineaxis-continuous-experiment.md)在正向约 26.15 s 时因 J4 超出已检查范围而中止，程序未确认停止，用户确认已经急停、机械臂停止并有支撑。重新供电及现场核验后完成的[原生单组定位](native-positioning-experiment.md)单独保存其执行证据。本文六组已完成实验及其模式恢复结论均对应各自采集时刻。

## 原始证据与现场范围

完整记录保存在 [`motor_sync_live_validation_20261030.zip`](../../../tests/data/motor_sync_live_validation_20261030.zip)。归档包含六组 JSONL、全部原始串口帧、逐帧复算、断电前后读取、用户卷尺说明、实际执行源码及配置摘要。`provenance.json` 逐项保存文件长度与 SHA-256；实际执行版本与审阅后的工作区版本分别标明。

归档 SHA-256 为 `6b4ad6fe6296a21c7a890c7ec367f35d6045853b2aab2ae3ba0efcdc5f00f019`，54 个数据及源码成员全部验证通过。原生实验的独立原始归档 [`motor_sync_timed_experiments_20261030.zip`](../../../tests/data/motor_sync_timed_experiments_20261030.zip) 保持原有内容，SHA-256 为 `6f61b0f18938ef789dfe74db7b0b4b067c07c35094521dd09106ff164aec45a0`。

九轴均回读硬件版本 `220905`、固件原始值 `16843008`，CAN 速率为 500 kbit/s；全部实验未发送 `0x1F` 属性写入、保存或设置零位命令。位置命令会更新运行参数；连续模式会采用其带宽。J4–J6 的预设自动回复启用，其余轴关闭，发送程序按各轴实际设置读取回复。

现场沿用用户确认的看护、急停按钮、支撑及运动空间。整个关节范围按全部 36 个非相邻凸 mesh 组合检查：J1 为 0.8–1.7 mm，J2–J6 为 ±0.15°，J7 为 −0.15°–0.65°，J8 为 −0.15°–0.75°，J9 为 −0.15°–0.85°。扣除要求的 10 mm 自身间距后，最小剩余裕量约 4.761 mm。该检查使用模型自身几何；完整外部场景、实际停止距离和断电支撑能力尚无独立验收结果。

## 两类实际发送方式

| 项目 | 原生共同时间 | 主机连续参考 |
|---|---|---|
| 九轴预设 | 每轴 `0x0C`，目标 float32、时间 int16×0.01 s、加速度 int16×0.01 rpm/s | 每轴 `0x0C`，目标 float32、第二字段 0、滤波带宽 int16×0.01 |
| 广播 | 节点 0，`0x08`，载荷 `1100000000000000` | 节点 0，`0x08`，载荷 `1000000000000000` |
| 参考 | 相同 30 s、相同 0.05 rpm/s，设备 `traj_mode=1` | 主机 Ruckig 共同 `s(t)`，20 Hz，最短运动时间 30 s，带宽 10 s⁻¹ |
| 主要正向目标 | `[1.5, 0, 0, 0, 0, 0, 0.3, 0.4, 0.5]`，mm／° | 相同 |
| 返回目标 | `[1, 0, 0, 0, 0, 0, 0, 0, 0]`，mm／° | 相同 |
| 完成观察 | 九轴完成状态、位置、速度及持续静止窗口 | 参考结束后继续发送 6 s，恢复原带宽，再发送九轴低速梯形终点保持并观察至少 5.5 s |

每类实验均包含目标保持组、正向组和返回组。目标保持组使用 J1=1 mm、其余轴=0°；实际起点与目标有差值时，设备会进行相应的小幅校正。正向组从 J1 约 1 mm 开始；返回组保持 J1 的非零 1 mm 目标。

连续参考的 J1 计划速度、加速度上限为 0.05 mm/s、0.01 mm/s²；旋转关节为 0.3°/s、0.3°/s²。六组实验均完成反馈观察。连续模式结束后，逐轴回读确认原 `control_mode=3`、`input_mode=5` 及原带宽恢复：J4–J6 为 66 s⁻¹，其余为 100 s⁻¹。

## 实际反馈比较

进度以各轴动作前四秒、结束前四秒的位置中位数分别作为 0 和 1，按主机请求／接收中点时间插值到 50 ms 网格。表中统计 J1、J7、J8、J9 的进度最大值与最小值之差；`t95` 是设备位置首次达到本次观测位移 95% 的主机时间。它们用于比较运动形状，目标误差在复算结果中另存。

| 接口与方向 | 最大进度差 | J1 / J7 / J8 / J9 的 `t95`，s | `t95` 最大差，s |
|---|---:|---|---:|
| 共同时间正向 | 34.357% | 26.695 / 19.607 / 22.594 / 23.952 | 7.088 |
| 共同时间返回 | 32.502% | 26.699 / 19.937 / 22.773 / 24.048 | 6.762 |
| 连续参考正向 | 2.318% | 27.905 / 27.966 / 27.968 / 27.870 | 0.098 |
| 连续参考返回 | 2.141% | 27.904 / 27.814 / 28.220 / 27.868 | 0.407 |

共同时间正向在约 19.95 s 时，J7 已完成约 100.25%，J1 为 69.23%，J8、J9 为约 66.38%、65.89%。返回复现了同类差异。J7–J9 末段还出现位置变化加快：按最近不超过 0.2 s 的实际位置变化估计，正向最大速度分别约 0.495、0.429、0.504°/s，返回约 0.509、0.392、0.655°/s。该原生接口没有独立的逐轴速度字段；本次相同时间和加速度参数不能表达所需共同进度。内部原因及短距离处理规则尚需本批次固件依据。

连续参考正向、返回分别保存 722 个完整九轴预设／广播批次，包括最后恢复带宽的批次。原始广播间隔分别为 44.882–53.474 ms、47.118–53.582 ms，中位数约 50 ms；广播之前九轴最新原始反馈的最大主机年龄分别为 74.533 ms、71.724 ms。各次预设节点、顺序、量化后的目标、带宽、广播载荷及终点保持均逐帧核验。

六组日志共 43290 条反馈与原始回复逐项相符，并重新计算速度与静止窗口。J7–J9 的动作前位置波动相当于本次小位移的约 1%–2.2%；设备采样时刻未知，主机顺序查询也存在时间差。2%左右的剩余进度差不能提供机械精度或完整同步验收结论。J2–J6 本次目标始终为 0°，其非零主要行程仍需对应验证。

## 非零位置断电核验

全部运动结束后，用户固定各轴姿态、人工断开并恢复电源，报告“已恢复供电，断电前499，断电后499”，并补充“499是到末端的距离”。499 mm 记录为卷尺测点到末端的距离；最小刻度为 1 mm，参照几何与测量不确定度未知。实际断电持续时间未记录。

断电前、后分别进行约六秒非运动读取，合计 3744 条快速反馈，全部原始属性及反馈离线回放完成。程序未发送运动、清错、设置零位或参数写入命令。

| J1 项目 | 断电前 | 恢复供电后 |
|---|---:|---:|
| 设备反馈换算的坐标中位数 | 0.9999985 mm | 1.0000475 mm |
| `encoder_turn_abs` | −57 | −57 |
| `zero_offset_counts` | 11145 | 11145 |
| 电池字段 | 4.012805 V | 4.100498 V |
| 卷尺测点到末端距离 | 499 mm | 499 mm |

J1 坐标中位数变化约 0.000049 mm，零位、多圈使能、身份字段、设备限位及本地坐标配置保持一致。九轴状态为 8，读取的五类故障均为零。J2、J4 的坐标中位数变化约 +0.077246°、+0.092212°；其余旋转轴变化保存在逐轴结果中。卷尺的单项末端距离没有提供各轴角度的独立核验，因此当前证据无法确定这些变化来自机械姿态、设备上电表示或其他原因。

上电还恢复了设备保存的梯形运行参数：

| 轴组 | 断电前速度／加速度 | 上电后速度／加速度 |
|---|---|---|
| J1 | 0.05 mm/s／0.01 mm/s² | 约 2.7775 mm/s／2.5 mm/s² |
| J2–J6 | 0.3°/s／0.3°/s² | 144°/s／180°/s² |
| J7–J9 | 0.3°/s／0.3°/s² | 约 199.98°/s／180°/s² |

此处来源为原始 `trap_velocity_rpm`、`trap_acceleration_rpm_s` 与 `trap_deceleration_rpm_s` 的前后比较，描述设备参数。上电检查必须重新核验执行模式和本次命令采用的速度、加速度。该次采集结束时停止记录要求启动审查；后续动作及当前停止限制见[九轴连续参考实验](nineaxis-continuous-experiment.md)。一次固定姿态断电记录没有覆盖 30 天保持、断电期间移动、全部返回区间或 J5 ±180° 边界。

上电运行模式另存于 [`motor_power_cycle_operating_20261030.json`](../../../tests/data/motor_power_cycle_operating_20261030.json)，SHA-256 为 `0f1730e967c1278661fd27c207152625d90b18bb92755da8f85ef58e90eb1ca2`。补充读取的 63 项属性、9 条快速反馈均与原始收发逐项复核，所有发送均为 `0x1E`。九轴仍为 `control_mode=3`、`input_mode=5`、`trajectory_done=1`，J4–J6 带宽 66 s⁻¹，其余为 100 s⁻¹，与连续实验前的模式及带宽一致。该独立 JSON 保存字段定义、采集源码与摘要，补充读取没有解除停止限制。

## 执行入口与复算

`DrEmpowerSerial` 提供默认关闭、互斥的 `timed_probe`、`tracking_probe` 研究权限，均要求明确的完整九轴位置连接。共同时间研究限制为 30–120 s、0.01–0.12 rpm/s；单次目标与有效反馈的差值最多为 J1 0.6 mm、旋转关节 0.6°。连续研究要求请求间隔 40–200 ms、带宽 10 s⁻¹；恢复带宽仅允许当前姿态附近目标。两种方式均检查完整目标、实际反馈和故障，广播前再次检查 200 ms 主机时效。几何范围、静止条件和持续观察由本次研究执行程序负责。

当前连续研究连接还必须提供 `TrackingProbeBounds`，使已检查区间同时约束设备反馈、自动回复及编码目标。范围违例在接收阶段锁定连接。该限制是在[九轴连续实验](nineaxis-continuous-experiment.md)后补充，归档中的历史采集源码保留原有身份；历史程序不能直接用来恢复现场运动。

归档中的 `run_timed_probe.py` 会连接设备并发送上述命令，只能用于已审阅的具体现场实验。通用 ROS live 入口和九值公开定位入口的实际执行资格保持既有要求。当前代码未将原生共同时间方式用于符合 D2 的单组定位；20 Hz 连续方式取得本次有限工况的接入证据，正式接入还需命令采用、通信中断处理、实际停止范围和全部轴动态验证。

离线复算使用归档中的 `analyze_timed_probe.py`、`analyze_power_cycle.py`，在[项目运行环境](../../joint_positioning.md#运行入口)下运行。将分析程序、六组 `*.jsonl`／`*.capture.json`、`before-power-cycle.json`、`after-power-cycle.json` 及 `power-cycle-operator.json` 提取到新的 `.scratch/<目录>/`；保留归档中的派生结果用于比较，不提取到本次输出位置。分析程序本身不创建设备连接。

```bash
python3 .scratch/<目录>/analyze_timed_probe.py --kind forward
python3 .scratch/<目录>/analyze_timed_probe.py --kind return --tracking
python3 .scratch/<目录>/analyze_power_cycle.py
```

六组原始记录、全部成员长度与摘要及源码身份验证通过。相关回归 206 项通过；广播前时效检查补充后的受影响回归 92 项通过，三个受影响源码文件通过类型检查。该时效检查的工作区版本与实际六组实验的执行版本在归档中分别保存；全部既有广播的原始反馈时效均满足检查条件。完整研究所需的设备规则见[设备确认事项](manufacturer-questions.md)，载荷和独立测量条件见[现场条件](field-conditions.md)。
