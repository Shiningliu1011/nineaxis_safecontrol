# J1 多圈计数实验与零位恢复

用户授权实机实验，并确认机械臂停止且有支撑。实验只向 J1 发送命令，持续读取九轴状态。关闭 J1 多圈计数后，设备保留软件限位，完成到达并保持 `40 mm` 的运动；独立回程记录完整覆盖 `40→0 mm` 及零位保持。重新启用多圈时，编码器错误 `512` 再次出现，在机械零位设置零点、清错并恢复闭环后恢复健康。

本次取得越过原约 `35.538 mm` 故障位置的局部证据。完整 `0–500 mm` 行程、上电绝对坐标保持和独立物理停止仍未通过验收。J4 连续运动异常的原因仍待查明，本次没有向 J4 发送运动命令。

## 实验条件

- 起始零位计数 `11078`，多圈使能 `1`，九轴状态 `8`、五类故障为零。初始原始证据见[机械零位核验](zero-reset-verification.md)。
- 临时写入 J1 `enable_multi_circle=0`，地址 `31207`、类型 `u32`。限位使能保持 `1`，设备限位保持 `−36000–1000°`。
- 原生位置命令采用 `mode=1`，内部回读 `control_mode=3`、`input_mode=5`。目标为 `0`、`40 mm`，对应设备 `0`、`−2880°`；速度 `0.25 mm/s`、加速度 `0.05 mm/s²`，对应 `3 rpm`、`0.6 rpm/s`。
- 每个目标要求到位并持续保持五秒。九轴故障、位置、速度、反馈时效及静止条件持续检查；同时读取 J1 内部位置与速度参考、输出位置、转矩、计数及设备配置。
- 当前模型的完整目标区间检查包含 36 组非相邻连杆，满足 `10 mm` 自身间距要求，最小剩余裕量约 `5.37056 mm`。该检查没有提供外部空间或物理停止证据。
- 传动、`cpr`、设备限位及 PID 参数保持原值。期间没有发送配置保存或重启命令；设置零点的持久化行为没有经过断电验证。

## 实际执行与原始反馈

| 记录 | 实际发送 | 结果与证据范围 |
|---|---|---|
| `counter-trial-01` | 零位保持、关闭多圈、`40 mm`、`0 mm` | 到达 `40 mm` 并保持后发送回零。回程开始约 `0.5 s` 时，反馈为 `40.010335 mm`，实验程序因 `motion_outside_requested_interval` 中止。完整归档含 35433 条九轴反馈；这份记录没有覆盖剩余回程。随后独立读取确认已经返回零位。 |
| `counter-trial-02` | 零位保持、`40 mm` | 起步时反馈 `−0.000191886 mm` 触发既有 `joint_limit`，程序中止。归档含 1792 条九轴反馈。设备原生目标继续执行，随后独立读取确认约 `40 mm`；中间过程没有连续记录。 |
| `counter-return-01` | `0 mm` | 完整记录从约 `40 mm` 返回零位并持续保持，含 30159 条九轴反馈。J1 最终反馈约 `−0.00000457 mm`，九轴健康。 |
| `counter-restore-01` | 恢复多圈使能 `1` | 写入后的属性读取没有回复，记录按原样保留未完成读取。随后独立读取确认多圈已启用，J1 状态 `1`、轴错误 `256`、编码器错误 `512`、`turn_abs=−2047`。 |
| `counter-zero-recovery-01` | 设置零点、清错、恢复零位闭环 | 完成九轴六秒静止观察；574 项属性读取、1746 条快速反馈逐项与原始帧一致。J1 零位计数为 `11045`、多圈计数为 `0`、多圈使能为 `1`。 |

实验程序的 J1 定位容差采用现有需求的 `1 mm`；独立关节范围检查继续采用既有下限，上限为本次实验的 `40.1 mm`。原始回放覆盖全部首次实验反馈，并保存首次中止对应的判断结果。第二次起步的范围违例保持拒绝。

第二次实验的原始属性读取显示，主机目标为设备 `−2880°`，起步阶段内部位置参考短暂为 `+0.0198796°`、速度参考为 `+0.0637124 rpm`。这证明设备内部参考曾指向相反方向；当前证据不足以确定其产生原因。反馈、内部参考和主机目标均保存原值。

程序结束后，已发送的设备原生目标可能继续执行。因此中止记录不能用作物理停止证据。本次通过分别完整记录的正向运动、独立回程和最终读取确认各自结果，没有连续覆盖整个往返的单份通过记录。

## 对后续修复的约束

关闭多圈可以在本批次、当前固件和保留软件限位的条件下越过既有故障位置。返回零位后重新启用多圈仍读到 `−2047` 和错误 `512`，因此该开关没有提供绝对计数容量恢复或扩大的证据。

本地使用手册物理第 13–14 页说明关闭多圈后的每次上电以当前位置为零位，重新启用多圈需要设置零点；范围故障需要设置零点后清错。本次恢复过程支持这项故障恢复方法。把多圈关闭作为长期运行方式，还需要解决固定机械坐标、断电后位置恢复和完整行程验证，不能据此关闭 #185 或 #192。
