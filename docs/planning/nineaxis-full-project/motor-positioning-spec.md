# 九轴电机定位与 J1 全行程规格说明书

状态：用户已确认需求；实现状态、设备能力与验收结果逐项记录。
发布：[GitHub #184](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/184)，标签 ready-for-agent。
来源：本会话 Q1–Q22 已确认决定及本地大然电机资料核查。
适用对象：ninezzhou 九自由度机械臂、九值 Python 单组定位入口及既定实验轨迹的真实执行。

## Problem Statement

实验操作者希望在一个 Python 程序中修改 J1–J9 九个目标值，运行后由机械臂自动完成定位、保持目标并持续反馈执行状态。J1 还需要在 0–500 mm 完整行程内任意定位，并在正式轨迹中平滑地前后往返。

现有 Python 入口已具备九值输入和低速定位流程。J2–J9 已有目标定位和回零完成记录；完整九轴定位因 J1 编码器异常中止。J1 曾在前往 50 mm 时到达反馈换算位置约 35.54 mm，随后出现轴错误 256、编码器错误 512。用户恢复零位后的记录显示错误清除，但完整行程仍未验证。另一轮较高速度试验中，J2 目标为 10°，反馈曾达到约 10.686°。

现有逐轴执行方式、当前实验速度、完整路线检查和设备计数证据，尚不足以证明本次要求的同步运动、完整行程及物理精度。规格需要同时规定最终行为、问题调查所需证据和通过条件。

## Solution

操作者修改完整的九轴绝对目标，J1 使用 mm，J2–J9 使用 °。程序读取并核验设备与当前位置，检查整个预定运动路线，按每轴已验证限制计算共同运动时长，通过同一个平滑进度完成九轴定位。全部关节到位后保持目标并持续监测。

正式路径跟踪沿给定的末端几何路径连续执行，运行时间由实际关节能力和载荷条件确定。J1 的换向过程具有连续的速度与加速度。单组定位和正式跟踪分别使用各自的运动语义，复用共同模型、设备坐标转换、协议和反馈处理。

### 已确认的验收要求

| 编号 | 要求 | 通过条件 |
|---|---|---|
| R01 | 九值入口 | 一组输入完整包含 J1–J9；通过启动检查后自动开始；输入、预览和报告明确单位。 |
| R02 | 起点与绝对坐标 | 从已核验的实际当前位置开始；目标相对于已有机械零位；相同机械位置对应相同项目坐标。 |
| R03 | 同步单组定位 | 按各轴限制计算共同运动时长，同步启动，并按共同平滑进度协调到位。 |
| R04 | 到位保持 | 全部关节到位后保持目标，继续监测位置、速度、反馈和故障。 |
| R05 | J1 完整行程 | 支持 0–500 mm 内任意有效起点与目标，包括 0→500 mm 和 500→0 mm。 |
| R06 | 平滑往返 | 正式轨迹内 J1 连续前后运动；换向时平滑减速至零并反向加速，速度与加速度连续。 |
| R07 | J1 定位精度 | 单点定位稳定后，独立测量的目标位置误差绝对值连续 5 s 均 ≤1 mm。 |

| R10 | 正式路径跟踪精度 | 在低速及较高速度工况下，整段末端最大路径误差均 <2 mm。 |
| R11 | 完整实验 | 连续完成一遍完整实验轨迹，包含其中全部 J1 往返；所需时长根据实际运行参数计算并记录。 |
| R12 | 断电位置保持 | J1 连续断电至少 30 天后，绝对位置和项目坐标仍有效；上电时检查电池状态和位置有效性。 |
| R13 | 实际验收工况 | 完整实验装配、安装实验工具并承受最大计划载荷；记录全部移动部件、工具和载荷的质量。 |
| R14 | 整段路线检查 | 启动前检查同步关节路线；检查发现自身碰撞或已知障碍时拒绝动作，保持原状态并报告原因。 |
| R15 | 真实能力与记录 | 速度、加速度和运行资格有明确来源；命令、驱动完成、实际稳定及独立精度测量分别提供证据。 |

在 J1 的 0 mm 和 500 mm 端点，行程边界始终生效。R09 的容许距离适用于仍满足行程限制的位置。

## Implementation Decisions

### D1 应用入口与模块职责

复用现有九值 Python 应用入口及定位执行流程。共同模型负责关节身份、范围和运动学；单位转换模块负责项目坐标与设备坐标；轨迹生成负责共同时间与进度；碰撞模块负责整段路线检查；执行与反馈模块负责发送、观察、保持、拒绝和报告。

单组输入采用完整 J1–J9 绝对目标。速度与加速度具有逐轴配置及来源记录。输入缺失、非有限值、单位不明或范围无效时报告具体错误。

单组目标在启动核验与路线检查通过后自动开始。到位后保持使能和目标并持续监测。已有多组手动流程保持其已确认的推进规则。

### D2 单组定位的共同运动进度

令 s(t) 为所有关节共用的平滑进度，起点为 0，终点为 1。各轴参考满足：

q_i(t) = q_i,start + s(t) × (q_i,target − q_i,start)。

s(t) 在单组动作中单调变化，各轴参考的速度与加速度连续，并与起点静止、终点保持相衔接。共同运动时长须同时满足全部关节已验证的速度、加速度、范围和实际设备能力。

单组定位的末端路线由该关节路线经共同运动学计算得到。发送参数、协议量化和电机内部插补应共同实现已确认的进度定义。同步启动与协调到位需要实际记录证明。

### D3 正式轨迹的连续执行

正式轨迹沿给定的末端几何路径连续执行。根据各轴真实限制共同安排九轴运动及参考进度，在精度和设备限制内缩短完成时间。

J1 在轨迹内部的正反向运动连续衔接，换向时平滑减速至零并反向加速。正式跟踪保持完整轨迹语义；单组定位的完成与保持语义适用于其目标姿态。R10 的验收覆盖正式轨迹的全部声明区间及低速、较高速度工况。

路径误差沿用项目已确认的几何路径评价定义：按路径顺序计算实际末端与对应参考路径的距离，端点使用三维距离。整段最大值要求严格小于 2 mm。运行时间、进度及同一时刻参考的三维误差另行记录。完整项目的其他已确认验收项由对应总体规格管理。

### D4 J1 传动、零位与完整行程

J1 为固定 base_link 上的移动关节，项目正方向沿既有模型的 +Z，范围为 0–500 mm。既有导程为 5 mm/rev，电机输出轴与丝杠直连，方向为 sign=-1。设备角度与现场零位角度之差记为 theta_rel_deg，则 J1_mm = -theta_rel_deg / 72。

设备控制单位采用电机输出轴 degree、rpm 和 rpm/s。内部减速比已经体现在输出轴量中。500 mm 对应 100 个输出轴机械圈；按减速比 36 对应 3600 个转子机械圈。编码器 turn_abs 的数值含义需由设备依据确定。

项目机械零位和设备内部零位可以通过固定标定关系对应。内部零位及其有效计数区间须覆盖完整行程，并保证上电后的相同物理位置对应相同项目坐标。内部零位选择依据计数范围和保存规则的验证结果确定。

旋转关节沿用共同模型的已确认范围；当前模型约为 J2–J4 ±90°、J5 ±180°、J6–J9 ±85°，精确数值和设备方向使用有来源的共同配置。

### D5 编码器异常调查与修复依据

J1 诊断必须明确设备型号与版本、计数单位、有效计数范围、零位设置对计数窗口的影响，以及错误 512 的触发条件。

取证内容包括设备身份、硬件与固件版本、gear_ratio、cpr、pole_pairs、turn_abs、pos_abs、转子位置、输出轴位置、零位计数、多圈状态、电池状态和故障。需要记录各项读取时间、同次设备配置及独立机械位置；字段适用性以本批次实际接口为依据。

通过不同已知机械位置之间的变化，核对输出轴角度、位移及编码器计数关系。修复方案须给出对故障现象的解释、完整行程覆盖依据、坐标恢复方式及验证结果。设备调整方案以已取得的厂家能力和实测证据为依据。

零位设置、设备限位和故障恢复需要保持既定项目坐标的物理含义，并分别保存处理及独立回读结果。

### D6 断电位置与上电检查

J1 的断电绝对位置保持目标为连续至少 30 天。上电检查电池状态、位置有效性、设备身份、零位配置及实际机械参考位置。断电期间发生的机械位置变化也应反映在恢复后的绝对位置中。

B25 双编码器与 B06 不同编码器版本分别按其实际规则处理上电位置。各轴上电后的项目坐标有效性均需核验。需要确认单圈返回区间、零位修正和模型边界的对应关系，包含 J5 约 ±180° 的边界表示。

### D7 位置精度、稳定与目标边界

R07、R08 采用独立测量的实际机械位置。定位稳定后连续观察 5 s，全部测量样本均满足相应目标误差要求。测量方法、时间覆盖、分辨率及不确定度需要能够支持通过结论。

设备反馈用于执行监测，静止判据结合位置变化、速度、轨迹完成状态和有效反馈。反馈噪声及其判据与独立机械精度分别记录，J1 与旋转关节明确各自单位。

R09 按运动方向统计到达最终目标后继续越过目标的最大距离或角度。关节范围和碰撞条件始终生效。

### D8 碰撞检查与异常处理

执行前检查从实际起点到目标的整个同步关节路线，使用共同模型、实际工具及已知场景。记录检查覆盖、模型与场景身份、结果及拒绝原因。

检查发现自身碰撞或已知障碍时，拒绝本次动作并保持原状态。必需检查未完成或身份无效时，拒绝发送本组定位命令。

运动及保持期间持续核验反馈。发生通信异常、故障、范围违例或执行拒绝时，终止本次流程并保留异常记录；命令发送、驱动完成和实际稳定分别记录。恢复依据对应故障处理与有效反馈证据。现有真实执行资格与故障检查继续生效。

### D9 实际工况和参数来源

最终速度、加速度和连续运行能力依据实际电机、供电、完整装配、工具及最大计划载荷确定。载荷数值目前待定；需要称量并记录 J1 搬动的全部部件、工具和实验载荷，记录安装、供电及环境条件。

参数和验收结果绑定具体设备、模型、工具、零位、场景及运行配置。计划参考和实际运动都应保存可复核记录。整段故障、拒绝和未完成状态保留在对应结果中。

## Testing Decisions

### 公开测试边界

主测试边界采用现有九值 Python 应用入口，检查输入、预览、执行记录、到位保持及拒绝结果。正式轨迹使用既有跟踪入口进行回归。沿用已经确认的外部行为，不增加新的公开测试入口。

好测试应验证实际可观察结果。现有真实管道输入、MuJoCo 动力学、原始设备记录回放和独立现场测量作为验证依据；各类结果注明证据种类。真实硬件行为需由设备及测量证据确认。

### 尚需查明的数据与证据

1. J1 本批次编码器的 turn_abs 单位、有效范围、零位窗口及错误 512 触发条件。共享上位机配置给出 −2048～2047 数值范围，批次适用性和机械意义尚缺明确说明。
2. 两份健康记录中，turn_abs 为 0 和 −42，对应随后取得的输出轴角度约 0° 和 −53.7168°。主机接收间隔分别约 2.642 ms 和 8.917 ms，设备采样时刻未知；同一零位计数为 7733。项目读取的地址、类型及符号已与厂家 SDK 核对。
3. 历史健康记录缺少当时的 gear_ratio、cpr、pole_pairs、转子位置及 pos_abs。后续单次只读记录取得 gear_ratio=36、cpr=16384、pole_pairs=14；各记录按各自时间和配置使用。现有证据尚不能确定计数换算比例及完整行程的具体修复方式。
4. 最大计划载荷、全部移动质量和实际供电工况待确定。最终速度、加速度及完整任务时长由对应测量取得。
5. 各轴编码器版本、上电位置返回区间、J5 边界表示、同步启动与到位时间差需要实际证据。当前已确认共同计划时长，时间差未单独设定数值门槛。
6. 30 天断电位置保持、完整行程、完整装配下的双向定位精度、越过目标量及整条轨迹最大路径误差尚待验收。
7. 厂家 S 形模式及密集轨迹参考接口的固件适用性、参考发送与插补的实际连续性需要验证。当前未设独立 jerk 数值要求；速度与加速度连续性已经确认。
