# [13] 初始逆解、入场退出与轨迹优化范围

## 背景

对应[#140](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/140)。当前九轴跟踪原蝴蝶圆柱路径，采用已确认的[模型](decision-136-model.md)、[路径](decision-137-path-reference.md)、[限制](decision-138-limits.md)、[碰撞接口](decision-139-scene.md)和[执行参考](decision-141-progress.md)。三种主比较方法为`pointwise_ik/realtime_coordination/predictive_coordination`，共同初态、限制、执行和评价规则见[总体规格](../../specs/predictive-coordination-control.md)。用户于2026-10-27确认本页完整方案。

本票确定共同五维初始目标、安全入场退出、预测初始值及逐点逆解方法，并规定AEB-RRT*、完整轨迹优化和引导构型的用途。实际实现与验收继续使用已有任务。

### 五维候选与选择

共同研究配置采用128个multi-start种子，每个目标最多保留32个不同有效候选；这是本票确认的算法规模。种子包括实际/上一有效构型和固定随机序列，序列、归一化关节范围、迭代上限、收敛容差、去重尺度、容量及计算预算写入版本化IK配置。实现#111测量该规模的资源需求，正式清单由#144固定；配置变化重新验证并产生新身份。

候选通过条件为五维任务残差、逐轴范围、当前场景query与有效时间。重复判定在按各关节有效范围归一化的空间执行，阈值明确登记；求解未收敛、碰撞、容量或预算不足各自保存原因。完整滚转角不作为任务通过条件。

初始目标依据共同的归一化关节运动、限位余量、几何余量及已验证过渡代价排序，权重和同分次序固定于配置。规划到达时间确定后按该时间的场景重新验证；最终采用目标绑定实际过渡与场景证据。

### pointwise_ik 的完整定义

1. 目标来自M01同一连续蝴蝶路径。采样基准包含原有序源参数及NURBS/轴向事件；相同空间参数的时间阶段独立保存。相邻节点合并或增加节点时，记录对连续位置/工具轴误差的界和事件保留规则，原目标身份持续不变。
2. 各节点使用上述128种子/最多32候选的共同五维IK接口。上一已选构型作为连续种子，其余固定序列和全部候选结果保存；过滤使用共同模型、任务、M07及CollisionSafety。
3. 从当前已选构型出发，按归一化相邻关节运动、限位与安全余量的固定局部代价尝试候选。记录每个候选与连接的通过/拒绝原因，按照已登记规则选择。所有候选均无法连接时明确失败。
4. 选定关节序列通过成熟插值库生成具有明确一至三阶分段导数的C2关节曲线`q_path(s)`。在连续区间检查五维任务、关节范围及几何；插值误差需要增加目标节点时，在同一算法、容量与预算内重新求IK并验证。节点通过和区间通过分别保存。
5. 执行时以该关节曲线为冗余构型安排，通过标量进度和共同运动/参考协调实现受限调速；实际Ruckig运动、工具误差、M07、场景及停止重新准入。在线QP/MPC按各自定义安排冗余构型，pointwise_ik的当前关节曲线和其重算身份明确保存。
6. 动态场景改变、实际状态无法接续或恢复需要新构型时，从最后有效`s_ref`及实际反馈重新构造后续候选/连接。保持有序分支和已完成覆盖，重算的次数、候选规模、预算及耗时全部记录。达到共同等待或计算限制时明确停止/失败。

pointwise_ik具有共同调速、暂停和恢复权限。暂停期间的构型调整仍须满足参考位置/工具轴及完整运动条件；恢复后接续同一已确认参考。每种方法都记录实际执行约束、初始化/在线/重算成本和全部失败。比较的正式时间边界与统计由#144/#169统一确定。

### 最新场景、失败与独立验收

#116在执行前视及风险触发重规划中使用最新场景和实际执行区间，保留任务、路径、分支与M06进度。参考、计划、几何或时间改变后重建相应证据；动态障碍物按请求物理时间查询，停止全过程处于同一验证区间。

验收包括可达/不可达首目标、自由滚转、不同冗余解、关节边界、初始碰撞、候选重复/容量/预算、入场中scene改变、点间任务误差或内部碰撞、分支断连、停止余运动、暂停重算、恢复及完整退出。#111/#115/#110/#158提供实际公开接口和原始结果，#125独立核验几何，#160/#166核验完整闭环，#144/#169核验三方法共同条件及统计。现场起点、标定、反馈和停止证据由相应任务取得。

## 供 spec 采用的要点

- 初始IK为位置加工具轴的五维多目标集合，共同模型、实际状态、任务容差和碰撞身份贯通入场退出。
- pointwise_ik保留多候选、确定选择、连续关节曲线及其重算身份，具备共同调速、暂停、恢复和执行检查。
- 连接、轨迹优化、引导构型和预测初始值分别具有用途、来源、截止条件及独立结果。
- 当前实际运动、参考及停止在最新场景中重新检查，M06保持实际区间和有序进度。
- 三方法的共同起点、条件、全部计算/执行成本及成功失败由#144/#169统一验证。
