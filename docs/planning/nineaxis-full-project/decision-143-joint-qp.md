## 实施安排

### 五维误差与共同变量

共同模型提供`p(q)`、工具工作轴`a(q)=R(q)[:,0]`及实际导数；M01提供`p_ref(s)`、单位工具轴`a_ref(s)`和分段一至三阶导数。`s∈[0,1]`为归一化最终弧长，`nu=ds/dt`，源参数、米进度和参考时间保持独立身份。

位置误差为`e_p=p(q)-p_ref(s)`。工具轴误差采用当前球面log表达在参考正交基的两个分量`e_a`，其范数等于真实轴向夹角；绕局部`+X`的转动自由。真实夹角独立使用`atan2(norm(cross(a_ref,a)),dot(a_ref,a))`复核。参考正交基随s变化的导数包含在完整误差导数内；源节点按M01左右侧规则计算，切换参考基时显式转换并保持物理任务一致。

`e=[e_p,e_a]`、`J_e=partial(e)/partial(q)`、`xi_e=-partial(e)/partial(s)`，因此理想速度关系为`e_dot=J_e*u-xi_e*nu`。`J_e`为5×9，`xi_e`为5维，`u`为9维目标关节速度。与现有米进度接口连接时`ell=L*s`，`xi_e=L*reference_rate`、`feed_m_s=L*nu`。位置和工具轴前馈来自同一参考及其导数。

M09输出目标速度，M10生成的实际Ruckig速度另有时间表达。上述瞬时关系用于建立当前QP；实际运动的任务、工具和安全条件由完整分段重新检查。

### 尺度、任务一致修正与目标

采用10维固定QP变量`y=[z,gamma]`，`u=D*z`，`nu=nu_scale*gamma`。`D`为M07逐轴正研究速度上限的对角矩阵，J1使用m/s、其余使用rad/s；`nu_scale=F_max/L`，当前`F_max=0.06 m/s`。`gamma`通常为0–1，暂停/端点由阶段约束固定为0，零进给起点仍使用同一变量和完整导数状态。

任务尺度取`W=diag(1/epsilon_p,1/epsilon_p,1/epsilon_p,1/epsilon_a,1/epsilon_a)`，跟踪使用M07位置暂停阈值1 mm和轴向0.2°。恢复/入场按自己的M07目标容差构造度量；实际检查仍使用对应独立边界。计算角度统一转换rad，代价与SI原始残差同时记录。

令`M=W*J_e*D`、`b=W*xi_e*nu_scale`、`A=[M,-b]`；以缩放后的SVD建立`N=I-M_pinv*M`。任务一致修正使用`A*(y-y_nom)`，冗余修正使用`N*(z-z_nom)`，同时包含关节和进给变化在五维误差上的共同作用。

单次QP最小化以下凸二次代价，`T_scale=1 s`用于时间量纲归一化：

`||T_scale*(A*y+K*W*e)||² + lambda_C*||T_scale*A*(y-y_nom)||² + lambda_N*||N*(z-z_nom)||² + lambda_F*(gamma-gamma_des)² + lambda_D*||z-z_previous||² + epsilon*||y-y_nom||²`。

共同研究配置为`K=8/s*I5`、`lambda_C=1`、`lambda_N=0.01`、`lambda_F=100`、`lambda_D=0.02`、`epsilon=1e-6`。上述为本票已经确认的算法参数，绑定归一化定义并保存来源；正则保证Hessian正定，最终原始约束独立复核。改变尺度或权重产生新身份，#144固定正式清单，#169保存全部计算和质量结果。

### 约束、求解与实际准入

| 约束 | QP及最终运动中的处理 |
|---|---|
| 进给和阶段 | `0<=gamma<=1`，再受名义允许范围、剩余路径、有效阶段和起终导数约束。最小正加工进给未配置；实际覆盖、停止与总时间按既有规则评价。 |
| 关节 | 共同位置余量、速度上限和逐轴局部可达速度范围进入QP；加速度/jerk范围由有效qdot/qddot及周期形成必要约束。Ruckig逐轴数组及整个跟踪/停止重新检查，目标速度通过不能替代真实曲线通过。 |
| 位置/轴向任务 | 在当前位于本阶段任务边界内时，使用`h_p=epsilon_p²-||e_p||²`和`h_a=epsilon_a²-||e_a||²`的局部线性CBF行`h_dot>=-kappa*h`，`h_dot`由上述完整误差导数计算。共同研究采用`kappa=5/s`；边界外恢复使用明确的误差改进条件和完整运动检查，不声明该初态具有正向不变性。 |
| 碰撞 | 使用共享CollisionSafety每条独立primitive的`h/gradient/partial_h_partial_t/cbf_rate`，形成`gradient*u+partial_h_partial_t>=-cbf_rate*h`。保留全身对象、行身份、固定容量与活动集合检查；碰撞行不可松弛，class-specific参数来自已验证artifact。 |
| 实际工具工艺 | M07能提供的当前仿射必要行进入QP，并保存线性化点与适用区间；实际TCP速度模长、切向进给及导数、路径法向加速度/jerk、工具轴与曲面距离由最终q(t)/s(t)及高阶导数检查。非线性全过程条件通过才允许执行。 |
| 反馈、scene及期限 | 有效State、模型/路径、时钟、场景覆盖、当前状态相容和deadline为准入条件。容量、导数或必要参数无效时立即拒绝依赖候选。 |

QP保持任务、工艺和安全边界的适用语义，不引入碰撞松弛。对局部约束与实际完整运动分别记录残差和通过状态。QP使用已有qpax和float64，通过原始单位残差、有限值、KKT、迭代及耗时复核；数值缩放后的通过结果继续转换回原始约束验证。

### 实际运动与参考协调

`ReferenceCoordinator`读取有效起始`q/qdot/qddot`及`s_ref/nu/nu_dot`、QP目标、共同时间区间、M01/M07及场景。先取得真实Ruckig关节分段，再求同区间C2参考分段，使起始值/一二阶导数连续、`0<=s<=1`、进给非负、参考速度/加速度/jerk满足M07，并在实际q(t)上满足五维与工具条件。

参考分段以分段常值jerk和解析积分重建，节点包含共同时间边界及所需运动/路径事件。协调问题以参考与名义推进的差和变化为目标，所需阶段、边界、实际任务及工艺为约束；成熟约束求解库产生候选，独立区间检查提供执行证据。节点检查和完整区间检查分别保存，不能只根据几个采样点或假设进给单调可行就接纳。

关节目标、参考或区间改变时重新生成和检查同一共同对象。候选搜索/参考协调的容量、候选顺序和预算显式配置、固定并记录；在预算内没有完整通过的候选时返回明确失败。参考不能直接替换为实际TCP投影，M06只结算M11具有执行证据的实际采用区间。

`LowerResult`保存输入State、计划/独立来源、QP矩阵/缩放/解/原始残差、目标u/nu、实际关节/参考分段、全部修改、任务与工艺复核、query/certify身份、时间与失败。M10的准入和M11的采用结果分别关联该记录。

### 停止、恢复与异常

零速起点使用有效零速/加速度反馈，参考从当前导数连续起步。暂停或端点请求产生实际受限减速，停止余运动及参考继续按#141结算；参考真正达到保持状态后进入`REFERENCE_PAUSED`。恢复允许参考固定下完整准入的构型调整，位置≤0.3 mm、轴向≤0.04°且正向候选等条件持续0.2 s后连续加速。等待30 s、总时限420 s、端点保持0.5 s及共同退出沿用#138/#140/#151。

不可行、非有限、超时、无效反馈/场景/任务、计划失效或准入拒绝均保留原因；只有最新状态下完整通过的候选可以采用。独立与预测协同按同一Runtime规则转换，无法取得有效运动时进入受检停止或已验证保护。软件停止请求及实际物理停止各自保存证据。
