# 预测协调控制实现方案与依赖

本页规定[总体规格](../../specs/predictive-coordination-control.md)的模块关系及实施顺序。现有可复用能力见[核查依据](requirements-evidence.md)。模型和求解器的正式选择由对应决定任务完成，各项实现状态以验收证据为准。

当前[DCOL 与双传感器规格](../../specs/dcol-collision-core.md)管理几何、碰撞和感知，[模块边界与清理规格](../../specs/module-boundaries-and-reuse.md)管理独立职责、接口、复用和入口。两份专项规格在各自范围内优先；现有功能整合与完整 MPC、完整逐点算法及正式比较分别验收。

## 共同输入与状态

M01 提供带来源的路径资产：原始曲线、工具执行轴、法向、坐标变换、弧长映射、连续性、导数、名义速度及规划限值。M02 提供实际机构的关节类型、单位、轴序、TCP、运动学和几何。M07 分别提供工具工艺与电机限制，M04 提供几何间距和碰撞对象。

共同关节数组、工具限制及阶段采用[已确认M07](decision-138-limits.md)，执行参考采用[已确认M06](decision-141-progress.md)。M07直接保存逐轴jerk及来源，M06对共同运动区间和执行记录独占结算；模型、路径、时钟、命令及配置身份贯通消费者和独立评价。

场景和碰撞采用当前专项规格。机器人使用 OBB，圆柱、工作台及占据单元使用具有完整覆盖的凸体；PCL/OctoMap 处理双源点云，两路时间、原点、标定与来源分别保留。几何外扩后共同使用 DCOL h=alpha-1，误差分项计入一次。三个公开操作按每个构型的目标时间、实际连续运动与完整停止验证必要空间；freshness、物理有效期和计算 deadline 分别检查。

共同对象、数据归属、int64 ns物理时间、N+1节点/N区间和生效采用规则见[已确认数据与时间](decision-142-data-time.md)。[已确认入场与比较定义](decision-140-entry-methods.md)规定共同五维目标、128/32候选规模、C2关节曲线的pointwise_ik、入场退出及各规划/初始化用途。具体实现继续按原任务依赖取得证据。

[已确认Runtime](decision-151-runtime.md)规定12个阶段、M07映射、加工许可及异常规则。M10检查最终运动与停止，M11记录实际采用，M06结算；无效反馈、保护请求和实际停止分别保存。sim/shadow/live按各自证据准入，现场参数与完整周期由对应任务测量。

跟踪目标采用现有蝴蝶曲线。新 NURBS 程序直接读取其原始 49 个控制点和 53 个节点，生成缺少的连续参考信息与版本化文件。现有缩放、旋转、平移和圆柱投影贯通最终几何、真实弧长与各阶导数；源 `u`、最终弧长、名义时间和索引分别保存。工具 `+X` 保持当前向内径向关系，连接处、投影退化、曲面距离及工作距离单独验证。

运行快照至少包含 `q`、关节速度、可用的关节加速度及来源、`s_ref`、`s_tool`、当前工艺阶段、上一已采用运动、执行区间、反馈时间、场景时间与版本。缺少必要状态时返回明确的不可用状态，状态估计具有有效范围和来源记录。

## 当前周期控制

保留 `moving_reference_task` 的五维误差结构及 `static_velocity_solver` 的联合变量。M09 根据独立模式的名义安排或有效 MPC 当前一步，在同一任务和限制下求取候选运动与进给。

任务一致修正采用[已确认M09](decision-143-joint-qp.md)：逐轴能力与进给归一化，五维任务和缩放零空间分别度量，固定10维QP使用共同研究目标参数。阶段任务、工艺、关节和不可松弛碰撞行形成候选约束，位置与真实轴向边界由最终实际分段完整检查。

候选通过公共运动模块生成关节短段 `q(t)` 及参考短段 `s_ref(t)`。当前 Ruckig 依赖集中在运动生成内部，从有效状态接续并检查关节速度、加速度和 jerk；取消以前完成模块规格 I08 的全部替代验收。消费者读取公共连续运动，参考协调计算同一时段 TCP、任务误差、工具运动和剩余路径。

`ScheduledMotion` 的区间表达需要同时保存关节和参考的时间范围、状态、导数、命令身份及检查结果。`reference_at_step`、序列化、ROS 调度、部分执行结算、恢复和独立评价共同适配。被拒绝的候选保留诊断，M06 只结算实际采用且有执行证据的参考区间。

## 预测问题研究

候选状态应能够表达 `q`、关节速度与加速度、路径弧长及参考速度/加速度；候选输入可采用关节和参考的加加速度，或采用能够证明同等运动连续性与约束覆盖的表达。状态选取需要与公共连续运动及实际反馈相容。

数学问题至少明确：

- 每个预测时刻的五维参考、任务误差、实际工具运动及工艺阶段。
- 关节位置、速度、加速度、加加速度及机构单位。
- 当前与未来障碍时间、距离、梯度、区间检查和停止运动。
- 正向有效推进、运动变化、任务保持和未来构型使用的目标与尺度。
- 起点一致、终点及停止条件、原始约束复核、不可行与超时状态。

运动学 NMPC、CasADi＋IPOPT 是已有研究输入。正式方案应以真实模型上的求解精度、原始约束复核、热启动、完整计算耗时、依赖及维护成本选择；预测周期、步长、节点数和时域由同一测量确定。

预测需要计入运动生成的过渡。可采用与执行器一致的预测状态递推，并通过公共运动结果核验预测当前一步；两者差异进入日志和下一轮起点。选择其他表达时，须说明如何约束执行差异并保持运动及停止检查完整。

## 接口与时间

| 接口 | 必需内容 | 写入归属 |
|---|---|---|
| `CommonConfig` | 模型、路径、坐标、工具轴、单位、约束、阶段规则、版本 | 配置加载与验收 |
| `State` | 真实或有来源的运动状态、`s_ref/s_tool`、执行证据和时间 | M05 汇总，M06 维护参考 |
| `UpperPlan` | 状态起点、生成时间、时间网格、有效期、关节运动与进给、预测进度、复核结果 | M08 |
| `LowerResult` | 当前一步建议来源、候选运动与进给、修正量、残差和状态 | M09 |
| 执行记录 | 获准关节和参考曲线、实际采用区间、反馈、拒绝与部分执行 | M10/M11，M06 结算 |
| 评价记录 | 计划、参考、投影三类进度与实际工具/关节运动 | M12 |

计划基于状态时刻 `t0`，生成时间独立记录。PlanReceiver 在命令生效时刻读取对应区间，校验任务、模型、场景、配置、状态和期限。异步求解期间下层继续按当前有效状态运行；失效计划进入已经确定的实时准入或停止过程。

## 方法与验证入口

逐点逆解方法复用多初值 IK、碰撞查询和完整运动连接能力。必须公开路径采样、候选规模、连续性、选择规则、重新计算条件、调速及停止恢复处理。M09 独立与 MPC 协同共用实时模块和恢复规则。

实际工具评价独立读取执行反馈。源时间律导数、工具 XYZ 导数、切向与法向分量分别记录；工艺检查根据已确认定义执行。配对实验固定共同配置，计划修正和电机利用记录用于解释结果。

以下现有文件提供可复用能力，正式调用通过对应公共模块和共同入口；各实施任务维护消费者与安装资源清单。

| 工作 | 主要文件或模块 | 验证重点 |
|---|---|---|
| 路径与源参数 | `path_following.py`、`ik_data_loader.py`、M01/M07 | 源资产、单位、`u` 到弧长、轴向转换、导数与工件关系 |
| 实时协调 | `moving_reference_task.py`、`static_velocity_solver.py`、M09 | 五维任务、共同变量、工艺与运动约束、原始残差 |
| 过渡与参考 | `static_motion.py`、`static_execution.py`、`static_control.py`、`static_recovery.py` | 加减速、停止余运动、参考连续、恢复进入工艺范围 |
| MPC | M08 与公共模型调用 | 多节点联合优化、热启动、当前一步、时间预算与原约束复核 |
| 调度与反馈 | `static_experiment_nodes.py`、M05/M06、Runtime | 生效时间、迟到/乱序、状态有效性、部分执行和三类进度 |
| 评价与方法 | `static_execution_evaluation.py`、`static_experiment_evaluation.py`、记录及报告模块 | 实际工具工艺、三方法身份、完整周期和可重算证据 |
| 九轴模型与实机 | M02/M04/M07/M11 | 九轴模型、可达初态、来源参数、真实反馈和停止能力 |

## 实施顺序

1. 取得并核验完整源资产、源参数、当前实现及模型身份；完善 M01/M02/M07 定义。
2. 定义实际工具指标、阶段、运动参考区间、M05/M06 和计划接口，更新独立评价。
3. 完成实时共同求解、运动参考协调、共用停止恢复与独立闭环验收。
4. 依据预测专题研究完成 MPC、当前一步接入和实际反馈滚动更新；验证时序与异常。
5. 完成逐点逆解比较方法；三方法采用[已确认验收方案](decision-144-acceptance.md)，由#169核验完整周期、正式清单、容量、30次配对运行及统计。
6. 按原完整项目继续感知、通用碰撞、系统集成和现场前置；通过对应准入后开展低速实机及正式实验。
7. 形成可追溯的理论条件、原始结果、图表、系统说明和复现交付。

原任务依赖保留各模块的并行关系，具体原生前置见[任务依赖](dependencies.md)。正式实验需要实际实现与运行证据，本轮文档检查仅确认规格和任务结构。

[三方法正式实验](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/169)汇合完整逐点算法、共同实验规则、总体要求、协同实机及[模块整合验收](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/204)。运行前检查共同条件并取得完整周期测量，随后固定清单、采集和统计；[项目复现](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/170)汇合通用碰撞、总体要求与正式结果。直接关系以[当前依赖表](dependencies.md)为准。
