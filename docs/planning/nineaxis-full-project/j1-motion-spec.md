## 已确认的运动定义

| 项目 | 定义与依据 |
|---|---|
| 电机型号 | 用户确认 J1 使用 `B06-PA-36-G`。 |
| 关节类型 | J1 为直线移动关节，滑台沿导轨平移，`base_link` 固定。现有模型的 J1 轴为 `base_link` 的 `+Z`。 |
| 现场零位 | 用户当前在上位机设置的位置定义为 J1 的 `0 mm`；对应编码器读数与设置方式需要保存。 |
| 正方向 | 用户确认：从零位向前运动，J1 位置增加。 |
| 电机方向 | 用户观察：上位机负角度对应向前，正角度对应向后。设备角度与关节位置的方向换算采用 `sign = -1`。 |
| 丝杠导程 | 用户既有记录为单头丝杠、`5 mm/rev`；一圈指丝杠转动一圈。 |
| 传动连接 | 用户确认电机输出轴与丝杠直接连接，`ratio_motor_rev_per_lead_rev = 1`。 |
| 行程范围 | J1 下限保持 `0 mm`，用户确认上限采用 `500 mm`。 |
| 位置目标 | 上位机角度为相对零位的绝对位置目标：`-360°` 表示零位向前 `5 mm` 处。 |
| 单位 | 操作与报告采用 mm、mm/s、mm/s²；ROS、URDF 与控制计算采用 m、m/s、m/s²。 |

以上现场观察来自本次用户说明。导程依据见[零位配置](../../../config/hardware_joint_zero.yaml)与既有用户记录；模型轴向和当前范围见[URDF](../../../models/ninezzhou/urdf/ninezzhou.urdf)。

## 模型起点与行程

用户确认：从原 URDF 的 `585 mm` 位置沿 J1 轴向返回 `500 mm`，得到新的 J1 起点。因此，新起点对应原 URDF 的 `85 mm`，新行程 `0–500 mm` 对应原坐标 `85–585 mm`。

沿现有 `base_link` 的 `+Z` 轴，坐标关系为 `q_old_m = 0.085 + q_new_m`。新坐标 `q_new_m = 0` 对应原坐标 `0.085 m`，新坐标 `q_new_m = 0.5` 对应原坐标 `0.585 m`。

按当前 J1 的轴向和旋转定义，模型修改目标为 `origin xyz="0 0 0.085"`、`rpy="0 0 0"`、`axis xyz="0 0 1"`，位置限位为 `lower="0"`、`upper="0.5"`。该固定位置修正属于模型定义；电机角度与位移继续按现场零位、`sign = -1` 和 `5 mm/rev` 换算。

模型使用确认后的起点、轴向及行程；生成关节链、碰撞 URDF 和来源身份同时更新。[模型坐标测试](../../../tests/test_j1_model_coordinates.py)与[MuJoCo 测试](../../../tests/test_j1_model_mujoco.py)核对新坐标 `0`、`250`、`500 mm` 与原坐标 `85`、`335`、`585 mm` 的各 Link、TCP 和下游碰撞几何。共同限制、规划和 J1 执行入口采用 `0–0.5 m`，旧模型标定身份被拒绝。模型与验证入口见[动作实验交接记录](../../joint_motion_handoff_20261028.md)。

## 位置换算

定义 `theta_deg` 为设备输出轴角度，`theta_zero_deg` 为现场零位对应的设备角度，`theta_rel_deg = theta_deg - theta_zero_deg` 为相对零位的角度。输出轴与丝杠直连，电机输出轴转数除以丝杠转数为 `1`。

厂家控制接口的位置和速度使用电机输出轴角度及转速。`B06-PA-36-G` 内部减速比为 `1:36`，该内部减速已经包含在输出轴读数中；设备到丝杠的额外传动比采用已确认的 `1`。

\[
q_{1,mm}=-\frac{\theta_{rel,deg}}{72},
\qquad
\theta_{target,deg}=\theta_{zero,deg}-72q_{1,target,mm}.
\]

| J1 绝对目标 | 相对零位的输出轴绝对角度 |
|---|---|
| `0 mm` | `0°` |
| `5 mm` | `-360°` |
| `100 mm` | `-7200°` |
| `500 mm` | `-36000°` |

相同的绝对目标始终指向相同位置。设备零位读数为 `0°` 时，发送角度等于表中数值；使用软件零位修正时，发送角度需要加上 `theta_zero_deg`。

允许的关节位置为 `0–500 mm`，对应相对零位的输出轴角度为 `-36000–0°`。ROS、URDF 和控制计算采用的范围为 `0–0.5 m`。

速度反馈的方向关系为 `v_mm_s = -speed_rpm / 12`。位置运动的速度与加速度幅值分别采用 `speed_rpm = 12 * speed_mm_s`、`accel_rpm_s = 12 * accel_mm_s2`，具体执行数值由设备能力与现场测量确定。

位置及速度换算依据见 [TransmissionSpec 与 UnitConverter](../../../src/robot_safecontrol_moveit/unit_conversion.py)。传动效率用于受力换算，位置与线速度换算由导程和传动比例确定。

## 设备限位接口

厂家 G 系列 Python 库提供 `set_angle_range(id_num, angle_min, angle_max)`。其完整函数读取当前位置，确认当前位置处于新范围后，写入 `axis0.output_shaft.circular_setpoint_min` 与 `axis0.output_shaft.circular_setpoint_max`，将 `axis0.config.extra_setting.enable_circular_setpoint_limit` 设置为 `1`，随后调用 `save_config()`。

按照已确认的 J1 范围，设备零位读数为 `0°` 时，配置值为 `angle_min = -36000°`、`angle_max = 0°`。使用软件零位修正时，两个值分别为 `theta_zero_deg - 36000°` 与 `theta_zero_deg`。实际配置使用已核实的 J1 节点身份。

厂家参数表将这两个输出轴限位定义为 degree 单位的可修改 `float32` 参数，地址分别为 `38010`、`38011`。本次设备已接受 `-36000°` 与 `0°`，限位开关回读为 `1`；程序发送配置保存命令后再次读回相同数值，断电后的保存与零位保持尚未验证。`set_angle_range()` 返回 `True` 的路径没有逐项核对写入后的参数，验收需要独立回读最小值、最大值和限位开关。

最近的[多圈计数实验与零位恢复](../motor-positioning/j1-multi-circle-experiment.md)显示，多圈使能为 `1`，零位计数为 `11045`，多圈计数为 `0`，设备实际限位为 `−36000–1000°`、限位使能为 `1`。厂家手册说明重新启用多圈后需要重新设置零点。B06-PA-36-G 存在不同编码器版本，完整计数范围与断电后的坐标有效性需要结合实际批次确认。

依据：本地[厂家 Python 库](../../../大然电机/大然电机所有资料/drempower-wiki-master/4-库函数/python/DrEmpower_can.py)的 `set_angle_range()` 完整函数、[库函数说明](../../../大然电机/DrEmpower电机库函数说明%20v2.1.pdf)第 33 页、[常用参数及地址表](../../../大然电机/大然电机所有资料/drempower-wiki-master/6-其他资料/DrEmpower系列电机常用参数及地址表.pdf)第 5 页，以及[使用手册](../../../大然电机/大然电机所有资料/drempower-wiki-master/1-产品手册及使用说明书/DrEmpower系列电机使用手册%20v1.0.pdf)第 14 页；页码均为 PDF 物理页码。

## 执行前需要取得的输入与证据

1. 现场零位的设置方式和实际角度反馈，设备置零与软件零位修正分别登记。
2. M11 的单轴绝对位置接口、有效反馈、限位回读与配置保存结果。
3. J1 的速度、加速度、到位容差和停止观察要求，保存数值、单位和依据。
4. 上电、断电和故障后的零位恢复，以及反馈、限位、停止及恢复条件。现场可用行程、停止距离与测量误差分别记录。

M11 任务负责执行适配与设备参数核验，现场测量任务负责真实零位、位移、停止与恢复证据。缺少执行必需的输入时，J1 保持拒绝执行。

## 规格验收要求

- 根据实际输出轴角度变化与独立位移测量，核对正反向换算、比例和重复性。
- 保存当前零位的编码器读数、设置方式、现场参考位置与模型零位的对应依据。
- 采用确认后的行程数值，核对模型、控制、规划与执行入口使用的范围；正反向及边界输入具有一致的检查结果。
- 操作、反馈与报告明确单位；绝对目标和相对增量分别具有明确含义。
- 按已确认命令形式核对实际发送值、反馈身份、时间、到位与异常停止证据；停止请求与停车观察分别记录。
- 设备参数、反馈或必需标定缺失时拒绝执行；当前 J1 执行能力以源码和实际验收结果为准。

## 当前实现与验证范围

[J1ScrewControl](../../../src/robot_safecontrol_moveit/j1_execution.py)读取[传动与行程配置](../../../config/j1_transmission.yaml)及[零位配置](../../../config/hardware_joint_zero.yaml)，复用 `UnitConverter` 和单关节反馈监控。J1 配置为 `sign: -1`、`zero_offset_deg: 0.0`。操作参数采用 mm、mm/s、mm/s²，监控内部的 `angle_deg` 为正方向输出轴转角，日志标明 `forward_output_shaft_deg`。

现有低速入口采用速度 `0.25 mm/s`、加速度 `0.05 mm/s²`，反馈速度保护上限为 `0.3 mm/s`，单次位移不超过 `50 mm`。目标范围检查采用 `0–500 mm`。这些数值属于当前实验配置，最终运行参数依据完整装配和最大计划载荷确定。

串口连接需要显式指定 J1 节点和移动关节类型。设备身份、故障、持续静止、当前目标或必要配置不符时拒绝发送运动命令。九值 Python 入口及 J2–J9 的定位、回零记录见[九轴手动定位](../../joint_positioning.md)。

[50 mm 实机验证](../motor-positioning/larger-positioning-experiment.md)从约 `32.0068 mm` 开始，最后有效反馈为 `35.5379808 mm`，随后 J1 状态读取没有回复。用户急停并重新供电后，独立读取显示 J1 驱动状态 `1`、轴错误 `257`、编码器错误 `512`、多圈计数 `−2047`，零位计数仍为 `11145`、多圈使能仍为 `1`。后续关闭多圈、保留限位的实验到达并保持 `40 mm`，另一次完整记录确认返回零位；重新启用多圈出现错误 512 后已完成零位恢复。最新九轴状态为 `8`、故障为零，原始证据见[计数实验与恢复核验](../motor-positioning/j1-multi-circle-experiment.md)。50 mm 与完整行程仍未完成，当前停止记录仍要求启动审查。

本次双向小范围实验测得约 `57.6` 个 `turn_abs` 增量/mm；当前方向在计数 `−2047`、位移约 `35.54 mm` 出现范围故障。原始收发已用于核对读取地址、类型、符号及项目单位转换；本批次完整计数编码、另一方向范围与覆盖 500 mm 的处理方法仍需设备证据。用户确认厂家无法补充说明，后续依据本地手册和[计数实验](../motor-positioning/j1-multi-circle-experiment.md)继续核验。设备内部采样时间与主机接收时间分别记录。

完整 `0–500 mm` 双向行程、实际载荷下定位精度、平滑往返及至少 30 天断电保持，按[九轴电机定位与 J1 全行程规格](motor-positioning-spec.md)逐项验收。原始现场证据继续由[运动参数与反馈证据](../../joint_motion_limits_evidence.md)及九轴定位记录提供。
