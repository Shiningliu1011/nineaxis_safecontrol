# [06] M01 工件路径与五维任务参考

## 背景

对应 [#137](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/137)。跟踪目标采用现有蝴蝶曲线，缺少的可计算信息由新 NURBS 程序生成新文件。沿用 #149、#136 已确认的九轴模型、`tool0`、局部工具 `+X` 和模型/标定身份。M01 为 IK、实时协调、预测、执行和评价提供同一连续路径与工具轴参考。

### 坐标、工具轴和工作距离

实际跟踪目标由现有加载、轨迹变换和圆柱投影链确定。生成器记录各阶段参数，将同样的变换作用于连续源曲线，并贯通最终位置、弧长和导数计算。仿真缩放具有独立身份；真实工件安装变换由现场测量提供。法向、执行轴、完整旋转与位置分别按各自定义转换。

连续工具轴保持现有任务的局部 `+X` 与向内径向关系。生成文件明确轴向坐标；导出采用源工具 `+Z` 表达时，按 #136 的 `C_source_tcp=Ry(-π/2)` 显式转换至当前工具 `+X`。完整滚转作为名义信息保存，五维任务沿用工作轴转动自由的规则。

读取当前曲线和场景中已应用的圆柱投影、路径半径、工件半径及工作距离。生成新文件时保留其已应用状态，分别验证表面距离、最近曲面距离、法向距离与切向分量。工件几何、场景或距离改变时重新生成相应身份，并重新核验几何一致性。

### 导数、接缝与阶段

源参数导数、弧长导数与时间导数分别标记。对位置，mm 弧长的第 `k` 阶导数转换为 SI 弧长导数时乘 `1000^(k-1)`；无量纲工具轴的第 `k` 阶弧长导数乘 `1000^k`。对归一化参数，再使用 `d^k/ds^k=L_m^k*d^k/dell_m^k`。

`nu=ds/dt` 时，位置和轴向采用同一链式关系：一阶为 `p_s*nu`，二阶为 `p_ss*nu^2+p_s*nu_dot`，三阶为 `p_sss*nu^3+3*p_ss*nu*nu_dot+p_s*nu_ddot`。实际 TCP 运动由 M02 根据实际关节运动计算，M10/M12 独立核验。

记录蝴蝶曲线的位置节点、轴向、姿态和名义时间阶段的事件及左右极限，验证圆柱投影的非退化范围。共同连续查询在内部节点取右侧、终点取左侧，原始数组保留其源侧别规则。跨越事件时检查相关左右运动量与 M07 限制；位置或执行轴不连续时，按具有验证证据的独立过渡和阶段条件连接。

暂停可以查询同一 `s` 的位置、轴向和空间导数。入场、起停、恢复、终点保持与退出按各自阶段连接，运动与参考覆盖同一时段并接受检查。

### 有序投影与独立验收

局部投影读取上一有效路径区间、时间和本次有效运动范围，返回连续路径的投影、分支、距离与有效性。自交、局部返回、暂停恢复、未完成和端点保持均保留有序性证据。`s_plan/s_ref/s_tool` 按总体规格分别维护，M12 检查未覆盖区间、实际路径距离、参考误差、真实轴向夹角和工作距离。

验收使用源数据、独立 BSpline/积分、逐阶差分及步长收敛核验位置、轴向、`u↔ell↔s`、名义时间律、mm/SI 换算及一至三阶导数；包含首尾、节点和接缝两侧、低速与停止状态。核验自由滚转、工作距离应用次数、来源身份及全部公共消费者的一致性。M07 物理容差、M02 真实安装、M12 覆盖阈值和正式清单按各自已安排任务提供。

## 供 spec 采用的要点

- 当前九轴的所有方法消费同一蝴蝶曲线、工具轴、连续 M01 表达、进度定义、坐标和来源身份。
- 原始曲线、时间律与实际执行量各自保存；空间参数和各阶导数带单位及左右规则。
- 工作距离按当前场景的已应用状态处理；工件几何、法向和执行轴分别保存。
- #152 实现及验证 M01，#138 确定工艺与容差，#165 提供真实安装与标定，#144/#169 固定正式场景与统计要求。
- 本页记录用户已指定的路径与文件生成安排；控制接入、连续导数和全路径验收由 #152 等任务取得实际证据。
