## 实施安排

### 数据与写入归属

| 数据 | 内容与规则 | 写入归属 |
|---|---|---|
| `ReferenceSegment` | 同一时钟区间的 `s/nu/nu_dot/nu_ddot`、分段系数、事件侧别、阶段、路径/配置身份；从同一表达查询与积分 | M10 根据最终关节运动协调生成，M09 提供候选 |
| `ScheduledMotion` | 运行、任务、模型、路径、配置、命令和版本身份；共同 `[t_start,t_end)`；关节与参考连续表达；生效起点；检查结果；停止后续运动 | M10/M11 按最终准入结果接纳 |
| `ExecutionReceipt` | 执行来源、时钟身份、运行代次、单调序号、命令 hash、已经采用的 `[t_a,t_b)`、实际反馈范围、拒绝或部分执行原因 | 仿真执行器或设备执行适配器 |
| `ProgressLedger` | 已登记命令、按顺序确认的区间、最后确认时刻、`s_ref/nu/nu_dot`、执行与参考有效性、未确认区间和拒绝原因 | M06 独占写入 |
| `ToolProjection` | 真实 TCP 与工具轴、路径分支、局部连续投影、距离、有效性、测量时间、上一有效区间 | M05 提供状态，M06/M12 调用共同投影接口 |
| `State` | 同一有效时刻的关节状态、上一采用命令、结算区间、`s_ref/s_tool`、任务误差、阶段与各自来源 | M05 汇总，其他模块只读取 |

全部区间使用带身份的单调时间；仿真 tick 明确转换为该运行的时间，时钟映射由 #142 定义。归一化 `s∈[0,1]` 为公共进度，界面需要弧长时使用同一路径总长 `L` 换算。源时间和规划时间独立保存。

参考曲线与最终 Ruckig 运动共同生成、共同检查，保存相同的起止时间、阶段和命令身份。最终运动修改后，重新计算参考并检查工具误差与工艺限制，随后生成对应证据。M06 不从求解建议自行生成已执行进度。

### 区间结算

在最后确认时刻 `t_a`，仅依据匹配的已采用命令与有效执行记录计算：

`s_ref(t_b)=s_ref(t_a)+integral(nu_exec(t),t_a,t_b)`。

积分使用 `ReferenceSegment` 的分段表达，跨越阶段、节点或命令时按其边界处理；导数和端点使用同一表达。结算同时核验关节运动、参考曲线、模型、路径、时钟和准入身份。

| 输入情况 | 处理 |
|---|---|
| 完整、连续且身份一致的已执行区间 | 从最后确认时刻连续结算，记录区间和积分依据 |
| 部分执行或提前终止 | 只结算执行器确认的有效子区间；保存剩余区间及停止/拒绝原因 |
| 已接纳但尚未生效、求解建议、被拒绝命令 | 仅保存记录，不增加已执行参考 |
| 完全相同的重复记录 | 根据序号、命令和内容身份进行幂等处理，不重复积分 |
| 同身份不同内容、重叠执行、倒退时间或区间越界 | 立即拒绝输入，保持最后有效结算及故障证据 |
| 乱序记录 | 在具有明确容量和等待期限的缓冲内等待；只处理从最后确认时刻连续相接的区间 |
| 缺失区间、反馈失效或缓冲/等待预算耗尽 | 标记执行与参考状态不可用；Runtime 根据 #151 的规则进入已检查的停止过程 |

执行参考的展示保留最后确认数值及其时间；状态不可用期间，MPC 和 Runtime 按有效性规则处理。M12 保留缺失区间，不把相邻样本之间未经证明的运动计入覆盖。

### 停止、暂停与恢复

| 阶段 | 共同运动与参考要求 |
|---|---|
| `ENTRY` | 参考锚定加工起点；连接运动通过相同的关节、任务与碰撞检查；满足加工准入条件后开始累计作业覆盖 |
| `RUNNING` | 最终关节和变速参考共同满足五维任务、M07 工艺及电机限制；按有效执行子区间结算 |
| `STOPPING` | 保存并执行已检查的停止后续运动；允许参考沿停止曲线继续推进，直至 `nu=0`；结算与真实采用区间一致 |
| `REFERENCE_PAUSED` | 参考保持，允许满足路径位置与工具轴要求的构型调整；加工开关和覆盖状态明确记录 |
| `RECOVERING` | 从有效实际状态和最后确认参考生成连续接续；满足误差、连续运动与工艺阶段条件后进入 `RUNNING` |
| `ENDPOINT_HOLD` | 参考到达终点且导数满足保持条件；实际工具端点、轴向、速度和持续时间独立检查 |
| `EXIT` | 关闭相应加工状态并完成退出连接；退出运动不增加加工路径覆盖 |
| `FAULT` | 保留已确认历史及未确认区间；恢复需要重新满足运行、时间、场景和状态准入 |

入场、停止、恢复和退出的工具限制按 #138 的阶段配置检查。暂停构型调整和覆盖统计分开记录。停止过程的剩余推进量进入参考结算，停止末端与路径终点分别保存。

### 重启、版本和投影

每次运行及设备执行代次具有独立身份，重启后校验持久记录、有效反馈、命令来源与时钟映射，确认从哪个区间继续。进程等待时间不自动成为已执行区间。路径/模型/配置变化使现有待执行命令与计划失效，重新建立身份一致的状态和连接运动。

`s_tool` 根据上一有效分支、实际反馈时间、允许的连续运动范围及路径误差进行局部有序投影。自交处保留分支，不以全局最近点替代执行顺序；发生无法消除的分支歧义时标记无效。实际工具的前进、返回和重复经过分别记录，M12 根据有证据的连续加工区间计算完整覆盖。

`s_plan` 保留计划生成时的预测值；`s_ref` 保留执行参考历史；`s_tool` 保留真实工具投影。下一次求解从同一时刻的实际关节状态与 `s_ref` 开始，并读取 `s_tool` 和任务误差。全部方法使用相同结算与评价规则。

### 公开接口验收

由 #155/#156 提供真实公开对象和执行适配器，#157 完成最终关节运动与变速参考共同生成；M12 独立重算。测试覆盖加减速、停止剩余推进、不同部分执行、迟到/重复/乱序/缺失/重叠、执行拒绝、分支自交、暂停构型调整、重新开始、身份变化和端点保持。实际导数、积分和运动来源由独立计算及原始反馈核验。

## 供 spec 采用的要点

- 所有方法共用 `s_plan/s_ref/s_tool`、归一化弧长、路径身份、同一运动时间及执行记录。
- M06 唯一维护执行参考；最终运动和参考共同生成、检查、序列化并按已采用区间积分。
- 停止余运动、部分执行、异常消息、重启与版本变化均有明确的状态和结算规则。
- 完整加工覆盖依据实际工具有序连续区间；端点参考、实际端点与完成状态独立检查。
- 本页确定接口和规则，时间预算、工艺数值、Runtime 准入与完整运行证据由其对应任务确认。
