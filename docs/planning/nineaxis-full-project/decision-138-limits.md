## 实施安排

### 公共配置与单位

建立有版本及内容 hash 的共同 M07 配置，绑定九轴顺序、模型/TCP/标定、最终路径、工件、场景和阶段。每项保存 `quantity/object/frame/value_or_bounds/unit/phases/source/assumptions/verification_state`。展示和人工录入使用 mm、°、s，控制计算集中转换为 m、rad、s。

源名义计划、研究配置、设备资料和现场核实值各自保存。缺失值明确记录未配置、所影响的检查、取得方式及责任任务。运行所需字段缺失时返回具体未满足条件，评价保留相应证据范围。改变数值、来源或身份后，重新检查计划、运动、停止和结果适用性。

### 工具运动和实际检查

| 参数 | 共同研究上限 | 对象 |
|---|---:|---|
| F | 60 mm/s | 参考进给和实际 TCP 速度模长；另存正向切向进给 |
| At | 100 mm/s² | 参考进给及实际切向进给的时间变化率绝对值 |
| An | 300 mm/s² | 源规划的 `kappa*v_ref²`；实际 TCP 加速度的路径法向平面分量 |
| Jt | 16400 mm/s³ | 参考进给及实际切向进给的二阶时间导数绝对值 |
| Jn | 16400 mm/s³ | 源规划的 `kappa²*v_ref³`及 Cartesian jerk 法向平面分量；实际运动记录并检查对应量 |
| delta / Ts | 0.001 mm / 2 ms | 源插补弦误差和采样周期，更改插值/执行表达后重新验证 |

归一化弧长为 `s`、总长为 `L` 时，参考进给为 `L*nu`，进给加速度为 `L*nu_dot`，进给 jerk 为 `L*nu_ddot`。它们与最终连续蝴蝶导数共同计算 Cartesian 运动。

实际 TCP 运动由实际状态与运动学计算：`v=J_p*q_dot`，`a=J_p*q_ddot+J_p_dot*q_dot`，`j=J_p*q_jerk+2*J_p_dot*q_ddot+J_p_ddot*q_dot`。路径切向 T 来自同一时刻的有效有序投影，切向进给为 `v_t=T·v`。其导数包含 T 随时间的变化，Cartesian 切向投影和进给时间导数分别保存。

实际法向平面量为 `(I-T*T.T)*v/a/j`；工件法向 n 的速度、距离和距离变化另行记录。工具局部 `+X` 为工作轴，绕工作轴转动自由；工具轴运动与完整旋转运动分别记录。位置与工具轴误差使用实际 TCP 和同一参考时刻计算，真实夹角使用 `atan2(norm(cross),dot)`。

最低正加工进给保持未配置。完整 XYZ 加速度/jerk 模长、工件法向速度专用上限及额外工具角运动上限保存字段和实际量；新增限制由工具工艺资料、使用者作业要求及相应试验提供。源 `Fmin=10 mm/s` 保留几何扫描用途，`position_tol=1e-6 mm` 保留数值检查用途。当前研究记录实际推进、暂停、完整覆盖和作业时间。

### 跟踪与场景判据

| 对象 | 共同研究判据 |

奇异性保留当前指标和阈值身份，五维任务按实际缩放及秩条件检查。三种方法使用相同限制；预测、实时、最终运动和独立评价保存各自复核结果。

### 阶段和期限

| 阶段 | 适用要求与结束条件 |
|---|---|
| 初始化/入场 | 身份、有效状态、关节、几何和完整停止检查；连接至起点，满足加工准入；研究观察时间2 s |
| 起步/恢复加速 | 从当前位置/速度/加速度连续接续，检查共同机械与工具上限；结束依据实际生成及执行区间 |
| 曲面跟随 | 共同工具、关节、位置、轴向与几何要求；按有执行证据的完整区间累计加工覆盖 |
| 减速/停止 | 共同运动和工具上限覆盖停止后续运动；参考继续结算对应剩余推进，直至保持 |
| 暂停/恢复检查 | 参考保持、有效构型调整及恢复阈值；等待上限30 s，确认时间0.2 s |
| 端点保持 | 完整覆盖、端点、轴向和停止状态连续通过0.5 s |
| 退出 | 使用独立退出连接，检查关节、几何和完整停止；记录实际结束状态 |
| 故障终止 | 保存原因、已经执行区间、剩余路径与全部失败；按对应准入恢复 |

研究场景总时限采用现有420 s，停止、等待和过渡均计入时长。状态切换不消除已经使用的时间。多轴过渡使用各次实际证明的时长；已有单轴模型的1.2 s结果保留其初始条件。

反馈停止判据、通信时延、计划/命令有效期和正式周期由 #142/#151/#144/#169 及设备测量确定。源2 ms插补、仿真执行周期、实时决策周期和MPC周期分别保存。

## 供 spec 采用的要点

- M07共同配置保存单位、物理对象、阶段、来源、假设和验证状态，绑定模型、路径、场景与版本。
- 源计划、参考、最终运动及实际 TCP 工艺量分别计算，三种方法共用原始限制及独立评价。
- 研究关节配置明确逐轴 jerk；设备能力和实际停车使用对应现场证据。
- 所有阶段、过渡、暂停、停止、终点和退出均有适用限制与时间记录，失败和未完成保留在结果中。
- 缺失工艺参数和现场事实具有明确取得方式，相关检查与验收声明其证据范围。
