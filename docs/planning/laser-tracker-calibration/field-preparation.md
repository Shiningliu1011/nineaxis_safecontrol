# 现场准备与数据要求

状态：供决定与现场准备使用的方案草稿。设备、安装几何及精度数值待确定。

现场整理与报告遵守[项目单位约定](../../units.md)：XYZ、尺寸和 J1 使用 mm，转动关节与姿态使用度；设备原始文件保留其原生单位，并记录转换依据。

## 设备与机构资料

| 对象 | 需要的资料 | 用途 |
|---|---|---|
| 激光跟踪仪 | 型号、校准资料、测量模式、量程、不确定度、坐标单位、时间与有效性字段、原始导出样本 | 判断测量能力并确定数据适配方法 |
| 靶球与安装座 | 型号、尺寸、球心定义、安装结构、重复安装方法、相对法兰尺寸 | 建立测量点与机器人模型之间的关系 |
| 机器人 | 实际轴序、方向、编码器输出单位、J1 导程与传动比例、机械基准、关节范围 | 将原始读数转换为可信关节坐标 |
| 独立基准 | 基座可测特征、参考点或工装定义、基准测量记录 | 固定待估参数的参考系 |
| 现场 | 固定方式、跟踪视线、工作范围、障碍与线缆、温度、负载、测量站位 | 确定有效测量与执行条件 |

当前 `config/hardware_joint_zero.yaml` 中的零位与方向为待核实配置；`config/drempower.yaml` 中的节点顺序仍需与实际关节逐项对应。核查依据见[项目接口研究](../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/project-interfaces.md)。

## 每次采集的记录

建议使用三类互相引用的记录，保存设备原始文件和读取它们所需的版本信息。下表描述必要内容，具体字段名及文件格式由[采样与数据决定](tickets/dataset-and-sampling.md)确定。

| 记录 | 必需内容 |
|---|---|
| 测量批次 | `session_id`、机器人/跟踪仪/靶球/安装座身份、模型与配置摘要、坐标方向、单位、安装批次、环境和负载、操作人、校准资料 |
| 原始样本 | `sample_id`、`pose_id`、J1–J9 原始编码器读数与逐轴采集时间、跟踪仪球心三维坐标与测量时间、两侧时钟来源、有效状态、窗口内读数变化 |
| 样本用途 | 拟合/独立验收标记、重复组、接近方向、靶球站位、基座与设备移动事件、异常原因、原始文件位置 |

派生的关节坐标需要同时携带换算参数身份。保留原始编码器读数，才能在零位参数发生变化后重新计算。

跟踪仪直接导出的 XYZ 必须确认其坐标系和单位。机器人的指令值、规划轨迹和反馈值分别记录，求解输入使用实际反馈。现有通信诊断可记录逐节点原始读数与接收时间；设备侧采样时间仍未知，因此采集入口需要保存逐轴时间跨度及稳定窗口的依据。

## 静态采集流程的准备要求

1. 记录安装及固定条件，完成仪器规定的初始化与检查，建立测量坐标和独立基准。
2. 在授权的现场执行条件下进入选定姿态；根据连续真实反馈和跟踪仪读数判断静止状态，具体时长与允许变化由设备和精度要求决定。
3. 对同一稳定窗口保存两侧原始数据、各自时间及有效状态。九个轴轮询时记录逐轴时间与窗口跨度。
4. 按已定义的规则关联窗口，保留重复采样和不同接近方向的记录。反馈陈旧、丢失跟踪、基准移动等情况需要明确标记。
5. 每次安装或站位改变创建新批次；重新确定受影响的坐标关系，并记录批次之间的关联依据。
6. 在取得拟合数据之前定义独立验收姿态的用途标签；验收数据用于最后评价。

编码器零点执行 `set_zero`、更改传动参数或重新定义关节方向时，建立新批次，并记录新旧参数的换算关系及其依据。每组数据保留当时的原始读数和参数身份。

这些步骤需要真实设备记录才能验收。静态采集仍需证明两侧数据属于同一个稳定状态。

## 姿态设计的判断依据

- 覆盖目标作业范围内的 J1 位置、臂部构型和腕部角度，并保留各姿态的可见性与可执行性依据。
- 用待估参数的灵敏度矩阵判断重复姿态是否增加有效信息；直线位移、角度和外参使用明确的参数尺度。
- 在满足测量与设备限制的候选姿态中改善最小奇异值及参数不确定度；结构性自由度通过独立基准处理。
- 包含同姿态重复测量与不同接近方向，以判断重复性和回差对结果的影响。
- 独立验收覆盖作业范围边界及与拟合构型不同的姿态；样本数量、具体姿态、稳定阈值在设备和安装条件确定后计算与确认。

可辨识性依据见[测量研究](../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/measurement-observability.md)。
