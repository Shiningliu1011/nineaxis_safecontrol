# 离线求解与验收设计

状态：研究与决定草稿。具体参数集、基准、数值验收条件由[决定与依赖](decisions.md)管理。

输入、参数表和验收报告遵守[项目单位约定](../../units.md)，使用 mm/°。以下模型公式与现有控制接口使用 SI，导入时转换为 m/rad，导出时转换为 mm/°。

## 坐标与观测

约定 `A_T_B` 将 B 坐标转换到 A 坐标。L 为激光跟踪仪坐标，B 为机器人 `base_link`，F 为模型所选末端 frame，`r_F` 为靶球球心在 F 中的位置。`r_F` 与 TCP 的关系由安装几何确定。轴向使用实际模型定义，跟踪仪与机器人坐标之间的关系由基准测量建立。

单个稳定姿态的预测观测为：

\[
\begin{bmatrix}\hat p^L_k\\1\end{bmatrix} = {}^L T_B\;{}^B T_F(q_k;\beta)\begin{bmatrix}r_F\\1\end{bmatrix}.
\]

取前三个分量与跟踪仪 XYZ 比较。`beta` 表示被明确选入的运动学参数；单个靶球提供位置观测，工具方向的独立验收需要相应测量证据。

## 关节换算

现有 `UnitConverter.encoder_to_joint` 使用：

\[
q_i=s_i(a_i-z_i)c_i,
\qquad c_{2\ldots9}=\pi/180,
\qquad c_1=\frac{\mathrm{lead\_mm\_per\_rev}}{1000\cdot\mathrm{ratio\_motor\_rev\_per\_lead\_rev}\cdot360}.
\]

`a_i` 是输出轴编码器 degree，`z_i` 对应 `zero_offset_deg`。J1 的 `q_i` 单位为 m，其余为 rad；`s_i` 为已核实方向。

若求解器以当前换算结果上的关节修正量 `delta_q_i` 为参数，则候选配置为：

\[
z_i^{\mathrm{new}}=z_i^{\mathrm{current}}-\frac{\delta q_i}{s_i c_i}.
\]

选择直接估计 `z_i` 时使用原始编码器读数构建预测。两种参数表达需要明确选择，并在文件中记录；方向符号与传动比例由其独立证据确定。每个零位参数记录唯一生效位置，反馈换算与指令换算使用同一组参数及互逆公式。

源码、模型来源及现有反馈能力见[项目接口研究](../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/project-interfaces.md)。

## 名义模型接口

名义几何采用 `models/ninezzhou/urdf/ninezzhou.urdf` 与已核对的 `NineaxisKinematics`。该接口中的 `ee_link` 对应 `tool0`，其 `world` 与模型 `base_link` 重合。任意末端安装点由末端完整变换和 `r_F` 计算；位置 Jacobian 需要对应这个球心位置。

本轮检查得到名义 `tool0` 距 J9 轴线 235 mm。靶球实际安装坐标尚未取得，球心模型仍需独立确定。[计算依据](../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/project-interfaces.md)

## 待估参数与独立约束

零位、基座外参、靶球安装坐标和几何参数需要逐项登记来源与约束。求解前检查哪些参数组合可以被测量区分；固定某个数值作为参考时，记录其物理依据与不确定度。

对全部测量构造残差 `p_measured - p_predicted`，按可信测量不确定度加权。对参数做有物理含义的尺度归一化，再分析观测 Jacobian 的秩、奇异值与相关性。数值收敛、参数物理可辨识、独立精度验收分别检查。

具体自由度和单靶球约束见[测量可辨识性研究](../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/measurement-observability.md)。参数边界、误差权重和秩判据需要依据设备资料、名义几何与实际数据确定。

本项目首个运动关节 J1 为直线关节，零位变化可以由自由基座平移吸收；末端 J9 的零位变化可以由完全自由的球心安装坐标吸收。方案需要分别取得 J1 的机械参考与末端安装方向依据。球心处于 J9 轴线上时，位置观测对 J9 零位没有灵敏度；名义 tool0 的轴线距离不足以代替实际球心测量。[推导依据](../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/measurement-observability.md)

## 程序需要具备的行为

| 环节 | 输入 | 输出或拒绝条件 |
|---|---|---|
| 数据校验 | 原始文件、批次信息、单位、坐标、身份、真实反馈 | 缺少关键字段、非有限读数、单位不明、重复身份冲突时报告具体问题 |
| 观测预测 | 关节换算、名义模型、安装参数、基座关系 | 与测量对象一致的球心 XYZ |
| 可辨识性分析 | 参数清单、独立约束、姿态及测量质量 | 自由度、参数相关性、尺度与数值条件报告 |
| 参数求解 | 拟合数据与已确认约束 | 候选参数、逐点残差、收敛信息与不确定度分析 |
| 独立验收 | 保留姿态、明确适用条件、精度要求 | 同一批数据上的标定前后误差、重复性及逐项通过判据 |
| 候选交付 | 已完成验收的结果、模型与数据身份 | 候选零位表、必要的模型参数、测量与验收报告 |

异常样本处理规则在查看拟合结果前明确，保留原始样本、排除原因及样本数量。真实结构误差、回差和温度效应需要在记录中能够追溯。

## 独立验收

位置误差定义为 `e_k = p_measured_k - p_predicted_k`。在已确认坐标关系下，报告欧氏距离 RMS、预先指定的分位数、最大误差、各方向分量及分区域结果。

| 验收对象 | 所需证据 |
|---|---|
| 球心位置预测 | 实际关节读数经固定的校准模型得到预测，与独立测量比较 |
| 任务目标到达精度 | 校准后的完整控制流程到达预定目标，以外部测量检验实际结果 |
| 各关节机械零位 | 对应独立机械基准与可辨识性证据 |
| 工具方向及其他 TCP | 姿态或额外目标点测量，以及相应安装关系 |

各项验收声明保持与其测量对象一致，具体要求由[精度与适用范围](tickets/accuracy-and-workspace.md)决定。

- 拟合参数、固定外参和安装参数对验收集保持固定；用验收集重新拟合的结果需要重新安排独立验收。
- 重复性由相同条件重复测量评估；不同接近方向单独报告。
- 零位参数的物理正确性需要对应的独立基准；末端位置误差变小只支持其测量条件下的定位结论。
- 工具方向、负载变化、温度变化和重新安装后的适用性，需要各自的测量覆盖。
- 数值阈值、测量不确定度的处理、最终适用范围保持待确认。

## 与项目运行时的接续

候选结果保留原始数据摘要、模型摘要、关节名称与单位、方向和传动依据、基准与安装身份、参数集、求解版本、独立验收结果及适用范围。启用时由现有模型接口和现场任务统一管理所加载的版本。

需要检查反馈换算、目标指令换算、FK/IK、规划模型和碰撞几何的关节定义一致。几何参数发生变化时，明确哪些模型资源需要重新生成及独立核查。实际启用依赖现场任务的测量与验收证据。
