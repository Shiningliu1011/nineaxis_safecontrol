# 单靶球测量能够确定哪些零位参数

类型：`wayfinder:research`；处理方式：AFK；状态：研究完成；负责人：Lsn。

归属：[激光跟踪仪零位标定准备](../README.md)。研究资料由当前 Trellis 任务保存。

## Question

对于首关节为直线关节、末端具有旋转关节的串联机械臂，在激光跟踪仪只测量单个靶球中心三维位置时，关节零位、基座外参和靶球安装坐标之间有哪些不能独立确定的组合？需要怎样的独立基准、安装几何和采样条件，才能判断本项目要求的参数可辨识？

区分结构性的自由度、数值条件、测量不确定度，以及仅测位置能够验证的结果。引用一手论文、官方技术资料或明确展示推导依据。

## Resolution

2026-10-26 完成文献与模型研究。自由基座平移可以吸收 J1 零位变化；完全自由的球心安装坐标可以吸收 J9 零位变化。这些关系需要独立基准处理。球心位于 J9 轴线上时，该关节转动对球心位置没有影响。

推导条件、测姿条件、尺度归一化与验收范围见[测量可辨识性研究](../../../../.trellis/tasks/10-26-laser-tracker-calibration-preparation/research/measurement-observability.md)。实际九轴可辨识参数数量与可达精度需要具体安装、参数集和测量输入。
