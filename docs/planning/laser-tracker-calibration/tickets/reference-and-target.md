## Question

哪些参数由独立测量固定，哪些参数交给求解器？机器人基座、J1 的零位基准、末端 J9 的角度基准和靶球球心坐标怎样建立可追溯关系？

需要用户结合机构与安装条件选择可执行的基准和靶球方案，并确认每个待估参数能够被现有测量区分。靶球安装方案同时满足可见性、刚性、重复性和关节运动区域要求。

参数自由度及需要的独立约束以研究证据为依据，具体尺寸与标定值由实际测量取得。
