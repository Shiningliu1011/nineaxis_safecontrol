# 取得设备能力与安装几何资料

类型：`wayfinder:task`；处理方式：HITL；状态：待资料；负责人：未领取。

归属：[激光跟踪仪零位标定准备](../README.md)。前置：无。

## Question

取得能够确定测量方案的设备与机构资料：

1. 激光跟踪仪的型号、官方操作资料、有效检定或校准资料、使用距离内的不确定度说明、实际可导出的样本及接口限制。
2. 靶球的型号、尺寸、兼容性、安装座结构、球心相对法兰或 tool0 的尺寸依据和重复安装测量方法。
3. 测量现场、基座固定方式、拟用独立基准、可见区域、遮挡和设备摆放空间。
4. J1 传动比例、行程与方向，九个节点到实际关节的对应关系，真实编码器读数的单位与时间记录能力。

用户已确认这些测量准备条件目前未具备。完成此事项需要真实资料，记录来源和取得方式；具体设备方案应依据精度与使用条件选择。
