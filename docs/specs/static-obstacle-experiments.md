## Problem Statement

依据用户提供的《开题报告》第 4、5 章，通过可重复的静态障碍物仿真实验验证九轴机械臂的三项能力：

1. 保持末端沿指定路径运动及工具轴方向，利用冗余自由度调整臂身，满足全身碰撞间距要求。
2. 障碍物和关节行程共同限制运动时，协调关节速度与路径进给。
3. 暂停路径进给后继续进行允许的构型调整，重新具备前进条件时恢复原路径跟随。

现有仿真、控制器和评价程序提供实现基础；本规格增加共同实验场景、联合求解、暂停恢复、完整自碰撞检查和基于执行反馈的对照评价。算法优势以固定实验集的测量结果为依据。

## Solution

提供统一实验入口，支持场景展示、单次运行、批量对照、数据重放和报告生成。ROS 2 控制器与带 Ruckig 运动处理的被控对象组成闭环，关节状态以 500 Hz 输出；MuJoCo 显示机器人、工件、路径和障碍物。

### 固定条件

| 项目 | 要求 |
|---|---|
| 机器人 | 九轴，一轴移动、八轴转动 |
| 末端任务 | 三维位置、二维工具轴方向，绕工具轴 roll 自由 |
| 参考点 | 位置与工具轴方向共同使用路径进度 s |
| 正式路径 | 完整蝴蝶轨迹；直线和圆弧用于基础验证 |
| 路径所在圆柱半径 | 270.6 mm |
| 工件圆柱半径 | 220.6 mm |
| TCP 目标作业距离 | 50 mm |
| 外部要求间距 | 30 mm |
| 非相邻连杆要求间距 | 10 mm |
| 主要球形障碍物半径 | 60 mm |
| 障碍物状态 | 整次运行保持固定 |

### 场景

| 编号 | 场景 | 验证行为 |
|---|---|---|
| S0 | 工件和台面存在，无附加球形障碍物 | 基础跟随、完成时间、构型变化 |
| S1 | 单个球形障碍物接近中间连杆 | 臂身调整、路径保持、外部间距 |
| S2 | 两个球形障碍物限制不同连杆 | 多条碰撞约束同时生效 |
| S3 | S1 环境中收紧 J1、J4 可用行程 | 行程与碰撞共同限制下的进给协调 |
| S4 | 当前构型暂时不能前进，存在可行构型调整 | 暂停、构型调整、原路径恢复 |
| S5 | 障碍物阻断必须经过的路径区间 | 安全终止、未完成范围及原因 |

S1、S2、S4 依据 S0 连杆运动，在路径弧长约 25%、50%、75% 处设置候选位置。正式场景须具有合法初态、符合要求的工具通道，以及未经避障调整的连杆运动会触及要求间距的证据。

S4 必须具有独立可行性见证：保持当前末端位置和工具轴方向，存在连续且符合全部关节、碰撞限制的构型调整，终态能够继续前进。证据不足的场景明确标记。

S3 以初始构型为基准，将 J1、J4 朝上下限方向的可用行程分别乘以 100%、70%、40%。

### 对照方法

| 组别 | 计算方式 | 恢复规则 |
|---|---|---|
| A | 进给与关节速度分离计算 | 基础恢复 |
| B | 进给与关节速度联合求解 | 基础恢复 |
| C | 进给与关节速度分离计算 | 改进恢复 |
| D | 进给与关节速度联合求解 | 改进恢复 |
| E | Generalized-SNS | 改进恢复，保留原算法任务缩放语义 |

A/B、C/D 比较联合求解；A/C、B/D 比较恢复规则；E 提供外部算法参考。全部方法共享路径、初态、障碍物、执行器限制、碰撞模型、构型辅助和评价程序。

## Implementation Decisions

### 任务与求解

- 使用移动参考模型 `e_dot = J_e(q,s) u - xi_e(q,s) nu`，u 为九维关节速度，nu 为路径进给；位置与工具轴误差由同一个 s 计算。
- 联合方法在同次优化中计算 u 与 nu，目标包含误差校正、期望进给、相邻周期命令平滑和共同构型辅助。
- 分离方法使用相同任务与约束，先确定进给，再计算关节速度。
- 关节位置、速度及碰撞约束不可松弛；求解失败、无效梯度或非有限结果不能形成获准运动。
- 静态约束采用 `h = d - d_safe`，时间变化项为零；每条有效碰撞约束分别参与计算。
- 构型辅助考虑近障碍物间距和归一化关节行程余量，通过五维任务零空间作用；形式、权重和速度限制在各组间一致。
- 新增参数只通过开发场景确定，正式实验前固定参数并记录选择依据。

### 几何与碰撞

- 坐标系统一使用 base_link；外部球形障碍物使用报告中的 OBB 表示，工件与台面参与固定环境检查。
- 自碰撞使用闭合 collision mesh 与 FCL，覆盖 base_link、Link1–Link9 的全部 36 个非相邻组合。
- 自碰撞 10 mm、外部 30 mm 分别配置、计算和报告。
- 接触、相交与实体包含均具有明确检测结果；只有有效距离及最近点查询才能用于约束和评价。
- 控制、过渡检查、显示和评价使用同一场景配置，记录尺寸、坐标、有效对象和模型身份。

### 暂停与恢复

- 状态包含 RUNNING、REFERENCE_PAUSED、RECOVERING、ENDPOINT_HOLD、FAULT。
- 暂停时 nu 为零，继续进行误差校正和允许的构型调整。
- 基础规则在当前状态重新允许正向进给时恢复。
- 改进规则同时检查位置误差、真实工具轴夹角及下一周期正向候选的可行性，连续满足至少 0.2 s；恢复阈值严格小于暂停阈值。
- 各组使用共同的进给渐增规则，每个周期重新检查候选运动。
- 单次持续暂停超过 30 s 时终止，记录进度、限制对象和原因。
- 几何或求解故障进入 FAULT；普通暂停恢复仅用于间距始终有效的状态。

### 执行、周期和接口

- 对经过与被控对象一致的 Ruckig 处理的候选运动重新检查关节及碰撞限制。
- 调整进给后重新计算相应关节运动；路径进度按获准进给和有效执行时间更新，被拒绝候选不推进参考。
- 候选周期为 20、40、50、100 ms。预热后选择全部方法完整周期 P99.9 不超过周期 80% 的最短候选，正式实验保持固定。
- 完整周期覆盖几何、恢复判断、求解、命令检查及同步记录，报告最大耗时和超期次数；全部候选不合格时报告运行时间验收失败。
- 提供场景配置、单次运行、批量运行、重放及报告入口，显式选择 solver_mode、recovery_mode。
- 记录配置、代码、模型、mesh、路径身份；候选命令、获准命令、反馈和时间；参考及实际有序进度；逐对象间距、有效性、状态转换、完成与终止原因。

## Testing Decisions

主要验收入口为“实验配置 → 完整仿真闭环 → 原始记录 → 独立评价”。复用现有跟踪平顺性验证中的实际控制器、被控对象与采集方式。数值测试验证任务导数、几何查询和求解正确性。

### 基础测试

- 直线、圆弧及连接处的任务导数，分别检查 q 与 s 的影响。
- 工具轴同向、接近反向及完全反向的真实夹角。
- mesh 分离、接触、相交、包含、最近对象切换及全部要求组合覆盖。
- 保存真实 QP 输入，使用独立求解器核对可行性、约束残差及目标值。
- 暂停时参考保持、关节可调整、恢复连续确认及超时终止。
- 命令拒绝、查询无效、求解失败和记录缺失的规定处理。

### 定量验收

| 指标 | 要求 |
|---|---|
| 路径距离 RMS / P95 / 最大值 | ≤ 0.15 / 0.5 / 2 mm |
| 真实工具轴夹角 RMS / 最大值 | ≤ 0.05° / 0.5° |
| 外部间距 | 全部有效测量 ≥ 30 mm |
| 非相邻连杆间距 | 全部有效测量 ≥ 10 mm |
| QP 成功率 | 适用方法 ≥ 99.9%，并满足命令准入要求 |
| 终点位置误差 | ≤ 0.5 mm |
| 终点工具轴夹角 | ≤ 0.5°，连续保持至少 0.5 s |
| 完成 | 按顺序覆盖完整声明区间并满足终点条件 |

路径距离、当前参考点误差和 TCP 作业距离分别报告。工具轴采用 0–π 真实夹角。评价使用执行反馈的正运动学与独立几何查询，候选、命令和反馈分别记录，缺失测量返回“证据不足”。

路径交叉位置使用连续有序的局部投影。跟随、暂停、恢复和终点保持分别统计，提供按时间与按弧长的结果。

### 正式实验

- 各场景采用三组合法初始构型及 0.5、1.0、1.5 倍名义进给，每个方法与配置组合重复三次。
- 开发场景与正式场景分别管理；正式坐标、初态、参数、区间和阈值在运行前固定。
- S0–S4 中预先取得可行性证据的配置用于完整跟随验收；S4 包含实际暂停恢复事件，S5 验收安全终止和原因。
- 恢复延迟从首次有效正向候选开始计时，同时报告恢复后最大误差和重复启停。
- 全部失败、未完成进度和无恢复事件情况进入统计。
- D 组的功能验收依据精度、间距、完整覆盖、终点和恢复要求；两项改进的收益通过配对数据分别报告。

## Out of Scope

动态障碍物、感知误差、真实机器人运动、接触作业、力控制及整套 CollisionSafety 架构迁移属于独立工作。本实验始终使用 sim 模式，结论限定于所使用的模型、执行器仿真、路径与固定场景。
