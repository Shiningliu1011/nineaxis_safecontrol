# 文档维护规则

## 存放位置

面向读者的项目文档统一存放在 `docs/`。仓库根目录的 `README.md` 是文档入口；`AGENTS.md` 是项目工作指令。代码、配置和工具指定的元数据文件按其自身用途保存。

## 页面组织

- 根目录 `README.md` 只写项目简介和主要链接；`docs/README.md` 按主题索引文档。
- 每篇文档集中说明一个主题。一个页面需要覆盖多个独立主题时，建立主题页面，并从原页面链接过去。
- 导读页面只写概要、目录及相关链接。操作步骤、参数、设计依据和验证记录分别放在对应页面。
- 文档之间使用相对链接。移动页面时检查入口、相互引用和代码中读取文档的路径。
- 历史研究和验收记录保留其原始证据；维护相关主题时检查篇幅与导航，必要时增加主题导读。

## 功能修改

讨论方案时正常说明方案和影响。方案确认并进入执行后，AI 在同一次修改中更新受影响的文档，包括运行方式、配置、接口、当前能力或验收方法。交付前检查链接与文档描述，并说明实际验证结果。

文档随功能修改仍可能遗漏。维护人员每月从近期功能变更、配置和入口开始检查对应说明，核对过时内容、缺失主题、失效链接以及导读页面的入口；发现问题后按主题修订。
