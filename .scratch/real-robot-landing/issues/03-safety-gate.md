# 03 — 安全网关（位置契约）

**What to build:** 真机命令的唯一卡口：反馈状态、位置命令、看门狗配置三者形成硬合同——任何超时、故障、限幅违例都会让电机进入零速保持并锁存停车原因，只有外部健康确认后才人工恢复；J1 在传动未标定前禁止任何运动命令。

**Blocked by:** None — can start immediately.

**Status:** done — 2026-08-22（实现+测试通过；依赖前置 P1 的项未核销）

- [ ] 规则：反馈超时/命令超时/急停/驱动故障/关节数不匹配/非有限值/速度或速率限幅违例 → 输出零速保持并锁存首个停车原因。
- [ ] 锁存期持续输出零速；仅外部监控确认健康后可清除（不自动恢复）。
- [ ] 网关只检验、不重塑：限幅违例是停车事件，不是裁剪后的继续运行。
- [ ] J1 传动未标定（require_hardware_executable）时，任何 J1 运动命令被拒绝。
- [ ] 全部触发原因参数化测试通过（含状态机全部转移）。
