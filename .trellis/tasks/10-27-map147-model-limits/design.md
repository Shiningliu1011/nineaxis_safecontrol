# 设计

## 行为归属

当前 `NineaxisManipulatorJAX` 复用生成的九轴关节链，缺少共同来源/标定身份及高阶实际工具运动入口。`MotionPlanner` 仅由全局 jerk_time 计算 jerk；共同研究数组需要逐轴来源。新增纯内核模块分别承担模型与 M07 规则，既有 ROS 和路径职责保持原有归属。

## 模型

`NineaxisModel` 读取版本化配置，使用 `urdf_parser_py` 与 `srdfdom` 读取现有格式，核对原 URDF、SRDF、mesh 与生成链身份。模型 revision、配置和源资产产生独立的 `asset_model_hash`；各份 `RigidTransform` 与 `ModelCalibration` 必须保存匹配的 `applicable_model_hash`。构建、加载和更新入口检查该身份，完整模型 hash 再包含标定记录，身份计算保持单向关系。复用真实 JAX POE 求值，并以同一 TCP 修正计算位置、工具轴、几何变换和导数。SE(3) 工件变换与 TCP 修正具有独立来源及验证状态；缺少实测数据时明确保存相应状态。

host 入口验证九轴 SI 输入；可微计算边界提供固定形状结果及有限性状态。实际关节状态保留样本来源、时间及模型 hash。JAX 方向导数计算位置和旋转矩阵的一至三阶时间导数，完整空间角运动由旋转矩阵导数计算，工具轴运动另行提供。

## M07

`ProcessLimits` 从一份 YAML 加载不可变参数，源元数据与数值共同参与内容 hash。SI 计算复用 `robot_units`。加载后的配置绑定共同模型、路径、工件与场景；新身份需要重新建立消费对象。

实际检查使用同一时刻的有效路径切向、切向时间导数、工件法向和任务参考。进给导数采用 `T_dot·v + T·a` 和 `T_ddot·v + 2*T_dot·a + T·j`，同时保存 Cartesian 切向投影及法向平面分量。源名义和执行参考按独立 layer 标识记录。样本、质量汇总和暂停判据读取对应参数的适用阶段；机械边界、恢复、端点及时间等固定职责验证其阶段集合。入场和恢复共同使用的误差阈值明确登记两个适用阶段。暂停信号进入阶段原因并阻止继续当前阶段。阶段检查报告具体违反、必需缺项与研究证据范围，不把缺失值转换为物理数值。

`MotionPlanner` 增加明确 max_jerk 数组输入；现有 jerk_time 调用继续有效，二者同时指定时拒绝。新增共同配置构造入口，Ruckig 与停止运动均消费同一逐轴数组。静态资源创建仅转交已有 execution_limits 的 max_jerk；该 hunk 单独交给 merger。

## 验证与相容性

测试从公开接口观察真实对象。URDF/MuJoCo 提供与 JAX 独立的求值，时间差分来自 MuJoCo 位姿采样。明确参数数组与独立 Ruckig 比较。已有研究入口的数值来源继续登记，三种方法的后续接入通过共同对象消费 M07。仅修改本票文件，主仓库未提交的 #108 与规划记录保持不变。
