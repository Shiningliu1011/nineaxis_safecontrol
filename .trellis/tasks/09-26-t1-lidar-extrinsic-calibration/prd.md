# [T1] 激光雷达外参标定与独立验收并写入真源

## 目标与来源

完成 [本票](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/95) 的真实 LiDAR 外参标定、独立验收、记录写入及部署身份核对。
范围由 [速度级 OSCBF 架构规格](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/79) 的标定流程第 1 至第 6 步规定；执行边界见 [统一执行地图](https://github.com/Shiningliu1011/nineaxis_safecontrol/issues/133)。

## 已确认条件

- 2026-09-26：用户确认 LiDAR 和支架已安装，尚未采集。
- 2026-09-27：用户已连接 LiDAR 和机械臂，确认尚未准备标定参考。
- 已确认 MID-360S 身份与实时点云接收，并保存连接检查样本；机械臂 USB 适配器已识别，用户授权的设备专用 udev 规则已提供持久读写权限。
- 本票已指派给 Shiningliu1011；检查时没有原生阻塞票。
- 当前任务保持 `planning`，正式求解与独立验收所需的靶标和参考位姿仍待确认。

## 需求

- 记录固定支架、安装座、走线与实际传感器身份；求解与验收期间保持安装关系不变。
- 核实实际点云 frame、字段、单位、时间来源和质量；测量需要纳入自体过滤的固定件。
- 求取从 LiDAR frame 到固定 `base_link` 的 `B_T_L`；保存数据身份、工具版本、参数和输出方向。
- 求解数据与独立验收数据分别记录；保存未参与求解的靶标位姿、重复测量及已知尺寸物体的参考测量。
- 通过独立验收后写入 `config/sensor_extrinsics.yaml` 的 `lidar` 分节，复用既有 schema 和身份算法，填写真实 provenance。
- 部署后取得节点启动日志和 `/perception/calibration_status`，核对实际加载路径、文件 SHA-256 与 `calibration_id`。

## 验收条件

- [ ] 安装状态、传感器身份、点云配置及固定件测量有记录。
- [ ] 真实数据求得 `B_T_L`，变换方向和单位可追溯。
- [ ] 独立外参验收满足位置误差不超过 20 mm、角度误差不超过 5°，并保存重复性结果。
- [ ] 已知尺寸物体的点云位置误差不超过 20 mm。
- [ ] 通过验收的记录写入唯一真源，`calibrated: true`，身份自洽；未实测字段保持 `null`。
- [ ] 完成重新构建与部署，节点实际加载身份和被校验记录一致。
- [ ] 标定记录、独立验收记录、启动日志与诊断证据写入本票评论。

## 执行前所需现场信息

- 标定靶的类型、实际尺寸、安装方式及可用的观测工具。
- 同一静态样本的真实九轴关节反馈或独立基座参考位姿如何取得，包含时间、单位和模型版本。
- 补充设备固件版本和实际点云时间来源；本次连接检查的设备身份、驱动入口与数据目录见现场记录。
- 独立验收物体的已知尺寸、参考位置与测量方法。

这些信息影响采集方法和验收证据，确认后更新 `design.md` 与 `implement.md`，再进入执行阶段。

## 约束

沿用地图规定的 sim/shadow/live 限制，本任务不发送真实机器人运动命令。现场人员负责所需的实体安装和姿态调整。
当前 `lidar` 配置仍为 `calibrated: false`；原始数据、独立验收和部署证据齐全前保持该状态。
