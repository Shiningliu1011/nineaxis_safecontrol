# 激光跟踪仪零位标定准备

## Goal

形成完整的标定准备方案，覆盖现场采集、离线求解和验收要求，明确开始开发与现场测量分别需要满足的条件。

## Requirements

- 使用本项目本地源码和模型作为接口依据，保留现有未提交改动。
- 测量对象为安装在机械臂末端的靶球中心；安装尺寸、测量设备和数据格式需要取得证据。
- 用户在本会话确认设备、靶球及安装座、测量数据均未具备。
- 关节零位标定为主要目标；几何误差对零位结果的影响必须分析，几何参数估计范围保持为待决定事项。
- 分别说明编码器原始读数、关节坐标、靶球位置、TCP 与测量坐标的含义。
- 明确参数可辨识条件、现场测量记录、独立验收方式和接入现有模型的要求。
- 精度数值、使用范围及现场条件以用户确认和实际测量为依据。
- 本轮交付本地规划资料与研究证据；正式项目关联为现有模型接口任务和现场标定任务。

## Acceptance Criteria

- [x] 本地准备入口包含目标、已有决定、待决定事项与资料链接。
- [x] 当前换算接口、模型来源与测量能力经过源码核查并提供位置依据。
- [x] 单靶球条件下的参数可辨识性有可追溯的研究证据。
- [x] 设备与安装条件、数据要求、采样和验收要求均有明确归属。
- [x] 已知事实、研究结论、建议与待确认条件分别标明。
- [x] 本轮新增文档链接、任务元数据和本地分析结果经过检查。
