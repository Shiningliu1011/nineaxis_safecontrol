# #175 全部非相邻连杆 mesh 自碰撞

## 来源与前置

本任务属于用户授权的 #171，验收依据 GitHub #175 和
`docs/specs/static-obstacle-experiments.md`。前置 #174 提供外部 FCL 查询、
共同候选运动和反馈记录；其完整运行检查继续保留在对应任务。

## 要求

- 使用现有闭合 collision mesh，检查 base_link、Link1–Link9 的全部
  36 个非相邻组合，要求间距为 10 mm。
- 外部间距与自碰撞间距分别配置、计算和报告。
- 保存 mesh、来源记录、URDF、查询库和完整组合清单的身份。
- 每个有效组合形成独立约束，接入控制和 Ruckig 后的连续运动检查。
- 接触、相交、包含、无效查询和求解失败均不能形成获准运动。
- 独立反馈评价保存每个组合的距离、有效性和最小距离对应对象。

## 验收

- [ ] 闭合 mesh 来源、全部 36 个组合及间距进入运行记录。
- [ ] 真实几何覆盖分离、接触、相交、包含和最近对象切换。
- [ ] 最近点和关节梯度通过独立数值核对。
- [ ] 外部与自碰撞限制共同用于实际控制及运动检查。
- [ ] S0、S1 实际反馈覆盖全部组合；缺少组合时返回证据不足。
- [ ] 更新几何来源、检查范围、距离语义及实际验证文档。
