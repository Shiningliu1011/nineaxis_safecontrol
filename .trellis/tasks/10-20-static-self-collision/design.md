# 自碰撞几何设计

`collision_geometry_sources.json` 指定十个现有闭合 mesh。加载时核查清单、
来源记录、URDF 及各 mesh 的 SHA256，使用 trimesh 读取 STL，确认封闭性、
方向一致性和凸性，再将原有顶点与三角形直接交给 FCL Convex。
运行时不生成新的几何近似。

索引从 base_link 的 0 到 Link9 的 9，所有 `j >= i + 2` 的组合均参与查询。
最近点距离沿法向的导数采用两个连杆点 Jacobian 的差。共同上游关节对组合
距离的导数为零；连续运动检查采用下游连杆相对上游连杆的运动范围上界。

外部查询继续采用机器人 OBB，mesh 查询只用于自碰撞。批量评价同时提交两类
对象及其完整组合，使用独立 JAX FK 的实际反馈变换。场景记录保存两类要求间距
和 mesh 身份。旧记录缺少 mesh 证据时保留证据不足状态。

测试使用真实闭合模型、真实 FCL 和有限差分；原始 mesh 顶点、面和平面限制
可用于独立距离核查。只对有效最近点计算约束。
