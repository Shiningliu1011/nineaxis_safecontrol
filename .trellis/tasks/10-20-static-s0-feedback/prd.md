# #172 S0 仿真与反馈评价

## 需求

来源为 #171、#172 和 `docs/specs/static-obstacle-experiments.md`。
采用固定起始构型，使用真实 ROS controller 与 Ruckig plant 运行完整蝴蝶路径。
所有消费者使用相同实验配置，仿真模式固定为 sim。

## 验收

- [ ] S0 包含工件和台面；路径半径 270.6 mm、工件半径 220.6 mm、作业距离 50 mm。
- [ ] MuJoCo 显示机器人、工件和路径，与控制使用相同配置。
- [ ] 500 Hz 反馈与命令分别保存，记录仿真时间和单调时钟时间。
- [ ] 从反馈计算路径距离、参考位置误差、真实工具轴角度、作业距离和有序覆盖。
- [ ] 明确跟随、终点保持、完成和异常终止，保存配置、路径、模型及代码身份。
- [ ] 保存的数据可以重放并重算相同结果，异常保留已有数据和原因。
- [ ] 未取得的碰撞测量明确为证据不足。
- [ ] 更新运行说明，完成真实闭环验证。

## 边界

本子任务建立共同实验入口与评价基础。后续子任务负责同一参考的五维任务、
外部与自碰撞约束、执行准入及 A–E 方法矩阵，验收状态分别记录。
