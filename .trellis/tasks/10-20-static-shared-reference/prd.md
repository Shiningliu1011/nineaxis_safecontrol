# #173 共享路径参考的五维跟随

来源：#171、#173 与 `docs/specs/static-obstacle-experiments.md`。
使用同一个以米为单位的路径进度 s 计算位置与工具 X 轴方向，roll 自由。

## 验收

- [ ] 五维误差、关节导数 J_e、参考导数 xi_e 满足
  `e_dot = J_e u - xi_e nu`；u 使用关节单位每秒，nu 使用米每秒。
- [ ] 真实机器人 FK 与独立有限差分覆盖直线、圆弧、连接处的 q、s 导数。
- [ ] 真实工具轴夹角覆盖同向、接近反向、完全反向；roll 不增加控制要求。
- [ ] 控制和记录使用相同参考；交叉位置进度连续有序。
- [ ] S0 完整闭环逐项报告位置及工具轴精度阈值。
- [ ] 更新任务定义及运行说明，全部实验方法共用此任务。
