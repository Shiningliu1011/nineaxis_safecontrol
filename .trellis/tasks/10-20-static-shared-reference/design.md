# 共同参考设计

## 数学定义

位置误差为 `p(q) - p_d(s)`。工具轴误差为球面方向的最短旋转向量，
在参考旋转的另外两个轴组成的正交基中表示，合计五维。
参考基随 s 变化，其导数包含在 xi_e 中。真实夹角使用 atan2(cross norm, dot)。
反向轴处方向导数不唯一，保留真实角度并将任务标记无效，不能形成控制命令。

## 代码边界

`portable_oscbf/work/moving_reference_task.py` 提供无 ROS 的 JAX 数值接口。
复用 `PathGeometry`、`sample_path_jax` 与机器人 FK/Jacobian。
现有控制器通过显式 `shared_path_reference` 配置采用共同参考，
实验配置启用此字段。后续实验求解器使用相同数学接口。

JAX 输出包含 e、J_e、xi_e、同一 s 的参考位置和旋转、真实夹角及 valid。
host 和执行边界核对 valid；控制门不能放行非有限或反向奇异任务。
已有生产配置的默认行为保持，实验配置和报告保存选择值。

## 检查

用真实机器人位姿与 SciPy 旋转计算独立误差，有限差分检查关于 q 和 s 的导数。
连接处按当前插值的右侧导数检查；端点进给为零。
完整 S0 使用实际 Ruckig 反馈评价，不使用控制器内部预测值替代反馈。
