# 将曲面路径 MATLAB 资产转换为 Python 并验证

## 目标

在 Linux 复现原始管道模型、路径画笔、NURBS、进给与姿态资产链，使用真实 MAT 和 CSV 验证，并推进当前地图的基线与资产任务

## 需求

- 完成本次地图中的基线核验和路径资产核验，依据原生依赖更新实际状态。
- 用户明确要求当前 Linux 电脑使用 Python 执行原始 MATLAB 程序的相同功能。
- 覆盖管道曲面、画笔路径交互及导出、三次 NURBS 插值、曲率与弧长、进给规划和插补、工具轴及连续姿态生成。
- 保留源字段、mm/rad/deg/s 单位、工件坐标、工具 +Z 约定、u 与弧长的区别以及实际算法约束。
- 原 ZIP、MAT、CSV、控制点及节点保持原始内容，并提供文件身份和跨设备交接入口。
- 保留用户已有的两份静态实验文档改动。

- [x] M01–M12 基线清单包含当前版本、源码入口、实际通过测试、未验证能力和缺失输入。

- [x] Python 对原始 407、480、743 点路径完成三次插值，并核对源控制点和节点。
- [x] 独立曲线求值、位置、法向、工具轴、弧长及导数与真实源资料在注明数值容差内一致。
- [x] 原速度规划及姿态导出的主要公开接口可由 Python 实际执行，保留求解状态与约束验证。
- [x] 完成隔离的公开接口测试和完整命令行运行，记录退出码与产物身份。
