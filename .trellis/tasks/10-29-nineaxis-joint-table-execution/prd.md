# 实现九轴标定姿态逐组执行与真实反馈保护

## 目标与来源

接续 `main` 的 `a95831b`，按本会话用户要求实现完整九轴 CSV 姿态的逐组位置运动、真实反馈监控及独立标定记录。关联 GitHub #164、#153；继承 `docs/planning/nineaxis-full-project/j1-motion-spec.md` 的坐标、传动与零位边界。

## 需求

- 每行包含 J1–J9 全部绝对目标，用户输入与报告采用 mm/°，计算采用 m/rad。J1 新坐标为 0–500 mm，`q_old_m = 0.085 + q_new_m`。
- 使用驱动器单节点梯形位置模式，速度及加速度必须具有来源且满足现有保护限制。结合真实原始日志核查限制依据、反馈、停车、通信和断电恢复。
- 每组全部九轴持续到位、反馈确认停车、保存测量记录后，才允许下一组。等待测量期间持续检查全部关节，故障、反馈超时、运动或停车超时立即中止且禁止自动重试。
- 相机与激光跟踪仪分别保存任务及测量记录。每组记录目标、实际反馈、耗时、误差、停车条件及拒绝原因，保留模型、配置、设备与原始文件身份。
- 真实动作需要用户在当前会话另行授权具体范围。保持本机运动锁定和 ROS live 关闭；本次可自主完成代码、日志分析、离线测试及非运动检查。
- 本会话明确授权更新交接及问题记录，并提交、推送至 main。

## 手动定位入口需求

用户已确认本轮功能：Python 文件顶部提供 J1–J9 的绝对目标入口，J1 使用 mm，J2–J9 使用 °。用户通过上位机恢复到既有机械零位，本轮不设置设备零点。单组和既有 CSV 均使用各轴梯形位置运动，各轴按自己的速度到位。

- 单组启动后定位；CSV 第一组及后续组由 Enter 启动。全部九轴反馈到位并停车后保持使能和原目标，等待期间持续检查反馈。运行结束后继续保持及监测，输入 q 正常退出。
- Enter 只在当前允许启动或继续的提示后生效；运动期间输入 Enter 不预约下一组。最后一组的 Enter 不重复运动。
- 用户确认正常实验结束后，输入 r 并回车才回零。回零是一组九轴全零绝对目标，沿用每轴速度、加速度和梯形模式；反馈确认到位后持续保持使能并监测，输入 q 并回车退出。回零结束本次实验，不继续原表格；运动期间的 r 不预约回零，故障和 Ctrl+C 不触发回零。
- 最大速度与加速度和目标放在同一 Python 文件顶部，逐轴可编辑。初值沿用当前低速入口：J1 0.25 mm/s、0.05 mm/s²，J2–J9 2.46°/s、0.3°/s²；有效协议数值在预览与报告中列明。
- 沿用位置、速度、轨迹完成及共同稳定判据。Ctrl+C 或异常终止本次序列，可信反馈与通信允许时请求当前位置保持，反馈未确认停止时如实报告，不自动重试。
- 用户确认失能后重力转动无法解决、设备没有断电自锁，并明确要求修复手动定位启动。当前现场条件为全部可能运动范围内无人、用户在范围外全程看护。有人值守手动入口可在真实闭环、故障、初始零位、静止与目标范围检查通过后执行；普通自动执行和 ROS live 保持原资格要求。真机目标为 `[50,10,-20,30,-30,60,10,20,30]`（mm/°）。用户随后明确授权该目标的真机测试；用户自行重置 J1 零点后，独立回读确认新零位计数为 11145。程序没有写入设备零位或设备参数。用户现已明确要求同步本地和远程仓库。
- 提供真实 CSV、终端输入、独立设备记录回放和 MuJoCo 动力学验证。有人值守入口绑定已审阅停止记录、设备和坐标身份，新的执行异常单独锁定，禁止自动恢复；现场条件和记录不能作为断电保持或独立停车证据。

## 当前现场结果与未完成验收

首组 `[50,10,-20,20,60,-20,30,-30,30]`（mm/°）已按本会话授权执行，轨迹参数采用 GUI 回读乘以 0.75，九条位置命令已发送。约 0.520495 秒后 J2 达到 10.686097°，超出目标 10° 的允许区间，程序中止并发送九条保持命令。J2–J5 的五秒位置范围未满足停车要求，用户操作独立急停并确认停止，随后恢复急停。没有完成原目标、自动重试、下一组或测量。

恢复急停后的独立回读显示 J5、J6 分别约 −79.05°、−59.22°，与保持末次约 +18.12°、−15.51°不同。用户确认失能后关节受重力自行转动，现场没有机械支撑或制动。当前锁定保存 `hardware_blocker`，在 I/O 前拒绝且不能通过 acknowledgement 清除。用户另行要求全零位置，已准备目标表但未执行；该请求不包含设备零点写入。

J1 新零位来自用户设置及真实回读，多圈开关 1、圈数 0、零位计数 7733。首组前实际限位为 −36000°–0°，项目目标仍为 0–500 mm，模型定义保持。程序没有发送零位写入或重启。

九轴真机快速到位与停车尚未验收；当前 J1 零位采用用户现场确认和同次通电回读，零位精度、完整行程与断电保持仍需对应证据。任务保留 in_progress。

归零前仅 J1 后退约 28 mm 的授权与拒绝证据保存在 `tests/data/j1_retreat28_preflight_20261029.zip`。用户自行完成归零后，该请求已经结束，不得继续使用原增量。当前零位的完整回读保存在 `tests/data/j1_operator_zero_20261029.zip`。
