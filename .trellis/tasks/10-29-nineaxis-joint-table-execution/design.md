# 九轴姿态表执行设计

## 行为与责任

`joint_table.py` 已负责 CSV、共同模型与设备目标导出，`JointTableProgress` 接收仿真状态。`DrEmpowerSerial` 当前仅提供单节点写入权限；`SingleJointMonitor`、`VelocityWindow`、`ArrivalWindow` 拥有设备反馈、运动与停车检查。本次扩展这些真实责任入口，复用坐标和保护规则。

新增九轴执行模块负责：每轴独立反馈历史、全部关节共同持续静止、每组运动和停车期限、测量等待与逐组推进、完整报告；串口扩展仅允许明确列出的九个节点发送位置模式 1，禁止广播和参数写入。执行准备、实际发送、调用返回、反馈确认分开记录。发送前逐节点重新检查真实反馈与配置身份。

## 资格与授权

本会话后续明确授权的一组目标采用独立 `SinglePoseCommissioning` 请求，绑定一行 CSV、设备、模型、配置、GUI 参数、停车噪声原始记录、旧锁定和期限。调试现场有人值守；请求尝试一次即消耗。普通 CSV 自动执行及 ROS live 维持原资格边界。原锁定仅在当次真实九轴共同停车与零位核对后归档恢复，调试结束重新锁定，调试不会生成传感器测量或发送下一组。

调试使用有来源的 `MotionBounds` 贯穿校验、J1 目标转换、串口发送与反馈监控，默认单轴限制保持。停车五秒窗口同时约束 0.01° 位置范围、0.02 rpm 位置变化速度、原始速度估计噪声相容范围和轨迹完成标志，再累计九轴共同 0.5 秒。噪声来自另一份真实静止记录，运动速度保护采用独立一秒窗口。故障报告保存拒绝的观察值与可信状态，拒绝数据不能用于保持。

实际首组触发 J2 区间保护，保持后仍无法确认全部停车。急停后用户确认重力使 J5、J6 自行转动，且现场无支撑或制动。该事实保存为硬件停止阻塞，`MotorStopLatch.require_recoverable()` 和单组 I/O 前检查均拒绝；回零表已经准备但不执行。后续需要具体物理停止证据，不能使用文件确认替代。

`joint_table_cli --execute` 继续在真实 I/O 前拒绝未取得现场资格的请求。底层单组调试通过明确的执行边界连接真实串口；原锁定字节归档，当前故障和硬件阻塞另行保存。验证区分纯状态机、完整真实日志、MuJoCo 和真机。设备采样年龄、命令采用关联、独立停止、碰撞路径、J1 断电零位与位移仍有证据缺口，不能由用户确认字符串、配置存在或离线通过替代。

默认低速指令保持 J1 3 rpm、0.6 rpm/s及转动关节 0.41 rpm、0.05 rpm/s。授权调试指令按 GUI 来源乘以 0.75：J1/J7–J9 为 24.99 rpm，J2–J6 为 18 rpm，加减速度为 22.5 rpm/s。名义参数和时间估算不代表完成物理运动或加速度验收。

## 故障与测量

任一关节失败即锁存任务中止，禁止发送下一组。保持命令只接受新取得且通过身份、时间、故障、范围与连续性检查的位置；不可信位置或通信失效时拒绝生成保持目标并报告需要外部停车。停止请求和持续停车确认分别保存，停止未确认继续拒绝执行。

九轴逐节点轮询保留各自 request/receive 时间，不能给所有关节补发同一新时间戳。到位必须包含全部九轴的新反馈及共同持续区间，已经完成的轴继续受监控。测量文件 SHA-256 在后台计算，主线程继续检查反馈；接受前重新核对文件与反馈时效。测量记录绑定 session、task、measurement_kind、pose_id，拒绝跨组、跨任务重复使用；测量文件存在只证明记录关联。每组独立保存准备、运动、完成或拒绝结果，准备阶段误差参照本组目标；非法时间不进入 JSON 数值字段。

## 修改范围

- `joint_table.py`：复用每轴参数、九轴命令与报告身份。
- 新增九轴执行与真实日志分析模块：管理真实观察和逐组状态，提供纯逻辑验证入口。
- `drempower_serial.py`：九轴位置写入权限与完整事务检查。
- `joint_table_cli.py`：报告、真实记录分析及资格拒绝入口。
- 相关测试与现场检查脚本：完整日志回放、MuJoCo 和禁止未授权 I/O。
- 交接及姿态表文档：当前能力、参数依据、命令、验证和证据缺口。

本任务沿用现有共同模型及 ROS mode 边界。OSCBF 高阶约束由后续研究任务处理。相机和跟踪仪现场采集任务分别保存；本次保留等待真实动作授权和资格证据的状态。
