# 实施与验证

1. 使用真实 FCL 几何测试外部分离、接触、相交、包含和最近点。
2. 实现统一场景查询、解析关节梯度和逐对象约束，以有限差分核对梯度。
3. 依据 S0 保存 S1 候选证据和固定配置，并接入显示。
4. 接入实验求解器与实际 ROS 闭环，记录输入矩阵和候选结果。
5. 使用独立 SciPy 求解核查实际 QP；运行 S0 与 S1。
6. 完成反馈评价和文档，按安全范围执行 trellis-check、规范与需求审查。

所有验证使用真实库、真实模型和隔离 sim。执行后检查的完整验收由 #176 负责，
此前结果不构成 Ruckig 运动准入证据。
